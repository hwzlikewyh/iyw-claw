# 原助理文档插件独立移植

这是作者制包入口，制品输出在应用构建资源之外。不会预装插件、下载用户组件、连接业务账号或调用生成工具。

```powershell
node plugins/office-ports/build.mjs --cache 'C:\Users\iyw\.zcode\cli\plugins\cache\zcode-plugins-official' --output 'D:\projects\iyw\reports\office-plugin-ports-20261106'
```

可加`--plugin documents|pdf|spreadsheets|presentations`单独制作。上游版本固定，源缓存只读；服务器工作区、main入口和资源声明改为原助理形式，复用现有插件导入器生成清单、工具契约、应用和运行时。

正式上传前增加`--min-client-version <已验证的宿主发行SemVer>`；值写入v2清单并参与摘要、下载及安装校验。省略仅适用于本地作者候选，新交互插件正式上传会被拒绝，不自动把当前开发版当作已发布最低版本。

清单声明当前受管Node环境支持的Windows/macOS/Linux六个平台键，不声明Windows 7支持。当前实机证据来自Windows，跨系统验收仍需补齐；平台声明不代替实机验证。

读取契约在隔离配置目录、空工作区和最小环境的独立进程进行；不复制宿主令牌。许可证、第三方声明、来源摘要和修改说明保留在包内。源视觉验收代理转换为当前代理使用的参考，不注册旧宿主模型或新子代理。

本轮制品为待验收版本。正式上传/发布前仍需真实宿主中的文档导入、预览、引用、导出、平台与安装/授权验证。文件制作所需工具沿既有受管环境准备，不把OfficeCLI或运行时打入市场包。

作者可用`preview.mjs --package <制品目录> --workspace <专用工作区> --data <临时数据目录>`进行本地预览，提供`--open <工作区相对路径>`可读取指定文档。预览仅监听回环地址，使用真实插件服务与现有面板/沙箱组件；正式账号、租约授权与云端流程须在正式宿主中单独验收。结束预览后会关闭自身服务并清理自身临时配置目录，工作区文档保留。

需要核对插件私有状态跨进程恢复时，可显式给出`--storage <专用状态目录>`；该目录由作者保管，预览退出不删除它。默认仍使用自身临时目录，不读用户正式插件数据。
