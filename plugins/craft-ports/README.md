# 原助理图像编辑器独立移植

```powershell
node plugins/craft-ports/build.mjs --source 'C:\Users\iyw\.zcode\cli\plugins\cache\zcode-plugins-official\photocraft\0.2.4' --output 'D:\projects\iyw\reports\image-editor-port'
```

仅制作应用构建资源之外的独立候选包，不自动安装/启用、上传或发布。来源固定PhotoCraft插件0.2.4及其记录的源码提交；源缓存只读。完整许可证/第三方声明保留，不删除或压缩成无法访问的声明。

正式制包增加`--min-client-version <已验证发行版本>`，写入不可变v2清单并由安装/下载门禁校验。省略时仅生成本地待验收候选，新交互插件不能直接完成云端上传。不能用开发包版本号推断宿主已发布兼容版本；本脚本不操作客户端发布中心或数据库。

WASM静态数据段的等长品牌文本替换保留内存地址和函数代码，验证模块后重新计算摘要。ArtCraft受限文字改成中性的上游说明；PhotoCraft名称改为IYW Editor，应用图标有独立MIT/Apache-2.0许可。Brotli压缩减小传输体积，服务端仍校验解压后的真实大小和SHA-256；这不改变上传限制。

复用现有插件作者工具生成契约与清单。编辑器桥按宿主提供的可信对话信息隔离；手动保存走宿主确认和当前设备下载，模型写工作区需要项目写入权限。本地实际编辑/导出和持久化已有证据，正式账号安装授权、撤权、原生保存及云端生命周期仍须验收；制品存在不表示已发布。

偏好和画笔通过仅供面板调用的`_iyw_state_read`/`_iyw_state_commit`写入`IYW_PLUGIN_DATA_DIR/editor-state/<conversation>.json`。目录由受管运行时提供，会话来自宿主可信元数据；页面不能指定存储路径。不授予沙箱同源访问。客户端仅实现本编辑器实际使用的Storage/IndexedDB子集，不能当作通用浏览器数据库使用。

存储使用版本比较、会话内串行写入及临时文件同步后原子替换。单个快照最多24MiB、2048条记录，每次最多512项；非法Base64、过时版本或损坏文件均拒绝写入并保留原文件。保存失败保留待写内容，设置可重试，画笔仍使用编辑器自己的重试入口；提交响应丢失时只回读确认，不重复写入。

启动时恢复已保存的界面设置后才开启偏好写盘，避免上游Web入口强制深色主题覆盖原设置。主动关闭页面等待持久化与插件确认，再移除iframe；失败保留页面。异常退出后，新页面等待原租约到期再连接，不抢占仍活跃的页面。文档/画布内容仍须用户显式保存或导出，私有偏好存储不代表自动保存作品。

小于640px的插件视口提供菜单、面板、选项和适合画布入口，触摸目标至少44px；先保存桌面停靠显示状态，收起占用画布的侧栏，再在恢复宽视口时还原。菜单内容与禁用状态来自实际引擎，当前返回的命令标签为上游英文，可按名称或命令ID检索。界面控制文案支持中英文。

菜单执行通过仅供面板调用的`_iyw_user_menu`排入原编辑队列，使用用户导出语义进入宿主保存确认；模型工具仍沿原项目写入路径。保存取消/失败保留原重新保存入口。放大状态下Escape请求宿主还原，面板自己的原生对话框先处理Escape。未增加文件访问、网络或同源权限。
