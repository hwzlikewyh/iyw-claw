# 0.1.19

- 补齐 runtime 的 12 个工具契约，兼容 0.1.333 客户端的启动校验。
- 修复工作台过早初始化和素材存储驱动缺失造成的沙箱白屏，工作区持久化不依赖浏览器存储。
- 每个画布单独同步，避免新建或切换项目覆盖其他画布；保留旧 main 场景的首次导入。
- 旧客户端尚无宿主模型转发能力时明确提示升级，画布和素材功能仍可使用。

# 0.1.18

- 声明 Widget 使用的本地模型网关和工作区存储 host-only 能力，修复启动时报 `Plugin app tool is not declared by its connector`。

# 0.1.17

- 修复 Widget 单文件内联替换导致外部脚本标签重复注入的问题。

# 0.1.16

- 接入上游 v0.20.0 的完整画布、图片、视频、提示词、素材与设置工作台。
- 配置、历史、画布和媒体保存在工作区；Agent 当前活动场景与画布项目同步。
- 文本与生图默认经当前 iyw 会话的本地模型网关转发，不再要求 iframe 保存 API Key。
- 本地模型网关暂无视频和音频生成路由；选择默认网关时会明确提示，不把请求发送到管理接口。
- 最低客户端调整为 0.1.332，以支持受授权的模型网关 App 能力。

# 0.1.15

- 继承 0.1.14 的跨盘图片上传、范围读取、并发保护、选区、视口与整画布导出修复。
- 最低客户端调整为 0.1.329，兼容当前插件协议与宿主 API。
- 补充上传模式和冲突处理的技能指引；不支持的操作应由宿主确认，不绕过市场或目录安全检查。

# 0.1.14

- 修复插件数据位于 C 盘、工作区位于 D 盘时上传和本地导入图片失败的问题。上传暂存位于工作区资产目录，摘要校验后同卷提交。
- 图片按请求范围读取，避免每个分块都重新把整张图片读入内存。
- 节点修改和删除发生版本冲突时停止自动重放，失败的拖动也不会在下一次交互中偷偷重试。
- 选区提交前读取最新场景版本；滚轮缩放合并保存，空白点击不再产生无效 revision。
- HTML 导出嵌入位图与连线，整画布 SVG/PNG 导出包含连线与负坐标区域。
- 补充上传模式和冲突处理的技能指引，禁止手工写入资产目录绕过完整性流程。
- 初次发布要求客户端 0.1.330；0.1.329 兼容声明见 0.1.15。
