# 0.1.22

- 生成结果为图片链接时，经插件素材通道下载、校验和保存后显示，修复沙箱拦截导致的 Failed to fetch。
- 下载失败保留结果链接；画布和工作台支持“重试下载”，只恢复已有图片，不重复调用生成接口。下载记录支持重开恢复。
- 兼容客户端 0.1.334 已有的直接模型接口，模型列表与生图不依赖新增的当前窗口扩展。
- 仅允许已声明的图片来源，拒绝内网地址、跳转、非图片与超限数据；下载不附带账号凭据。
- 旧版本 Failed to fetch 未保存图片链接时阻止盲目重试生成，并明确说明无法恢复旧链接。

# 0.1.21

- 通过宿主窗口桥接绑定当前窗口、会话和选定模型；只有绑定校验成功才显示连接状态。
- 模型列表和生成直接使用宿主鉴权接口，停止自动发送模型查询或生成任务到聊天队列。
- 画布任务进入当前窗口输入框的同一发送流程，新建会话也可正常启动；切换窗口、会话或后端时拒绝跨上下文发送。
- 未提供窗口桥接的旧客户端明确显示不可用，保留画布和素材功能，不伪装已连接。

# 0.1.20

- 画布 Agent 连接原助理当前会话，显示实际宿主连接状态；发送任务时同步当前画布和选区，保留发送失败的输入。
- 旧客户端通过已有会话通道调度受授权的文本与图片接口，按选定模型生成并回填工作台；新版继续使用本地模型网关直接转发。
- 模型列表从原助理使用的真实模型目录同步，按能力分类并显示正式名称；移除写死的默认型号，保留失效选择并阻止生成，支持手动刷新。
- 生成任务支持状态查询、错误回填和取消等待，不自动重新发送或重试计费；取消等待不会中止原助理已开始的执行。
- 模型接口与管理接口仍分开，不向插件暴露账号凭据。

- 修复工作台过早初始化和素材存储驱动缺失造成的沙箱白屏，工作区持久化不依赖浏览器存储。

- 旧客户端尚无宿主模型转发能力时明确提示升级，画布和素材功能仍可使用。

# 0.1.16

# 0.1.14

- 修复插件数据位于 C 盘、工作区位于 D 盘时上传和本地导入图片失败的问题。上传暂存位于工作区资产目录，摘要校验后同卷提交。

- HTML 导出嵌入位图与连线，整画布 SVG/PNG 导出包含连线与负坐标区域。
- 补充上传模式和冲突处理的技能指引，禁止手工写入资产目录绕过完整性流程。
- 初次发布要求客户端 0.1.330；0.1.329 兼容声明见 0.1.15。
