# IYW 场景手册

本手册依据 `ai.iyw.cn` 当前页面、初始化请求和前端 source map 整理。它是
快速选工具和组织提示词的操作参考；点数、模型、可用渠道和权限必须以实时配置为准。
网页初始化接口的字段可用于理解路由，不等于允许 agent 绕过 CLI 或网关直接调用。

## 快速选择

| 用户要做什么 | 首选入口 | 关键输入与设置 |
| --- | --- | --- |
| 普通纯文生图、动漫、人物形象 | `imagegen` | 从 Fusion 图片模型目录选择可生成模型；只展示名称 |
| 明确指定 IYW 分身或多平台比稿 | `fission-generate` / `/GenerateAI` | 提示词；默认单平台、通道四；比稿才多平台 |
| 一张基准图首轮出一张设计图 | `tool variation` / `/styleVariation` | 1 张图、模型二、`batchSize=1`、同命令等待 |
| 一张图明确改色/换材质/改细节 | `tool variation` / `/styleVariation` | 1 张图、改动提示词、模型二、`batchSize=1` |
| 同系列新品 | `tool extend` / `/extend` | 基准图、保持语言和延伸方向、模型、比例 |
| 多张图融合 | `tool mix` / `/mix` | 2-10 张，按引用顺序，融合提示词 |
| 产品与配件组合 | `material-product` / `/comFangle` | 产品图、辅料 1-5 个、产品是否允许改变 |
| 图案或 IP 上产品 | `pattern-apply`/`ip-apply` | 图案/IP 图、产品图、授权和保持项 |
| 电商交付 | 商品套图 / `/product-kit` | 最多 3 张原图、平台、国家、语言、比例、7 张结构 |
| 只改背景 | `outpaint` 或更换背景 | 原图、背景/主体/场景/氛围；单图或多图模式 |
| 清理、增强、格式化 | 专用 `tool` | 原图、专用设置，不要用 variation 代替 |
| 一张基准图做企划案版面图 | `tool variation` / `/styleVariation` | 直接生成一张完整版面图，不写文档 |
| 明确写企划文档/分析报告 | Agent/需求解析/知识库 | 用户明确要求文字或文档交付时才进入 |

实测页面路由：`/GenerateAI`、`/styleVariation`、`/extend`、`/mix`、`/productFission`、`/comFangle`、`/imgUse`、`/ipUse`、`/product-kit`、`/aiTryOn`、`/modelScene`、`/paint`、`/instruction`、`/fusion`、`/expand`、`/amplify`、`/upscale`、`/splitLayer`、`/enhanceImage`、`/extractImage`、`/returnLeftright`、`/imageTiling`、`/convert`、`/lineExtraction`、`/lineart`、`/singleLineDraw`、`/3dmodel`、`/4dmodel`、`/imgToVideo`、`/backgroundReplace`、`/BackgroundRedrawing`、`/threeVisions`、`/matting`、`/removeWaterMark`、`/bleedLine`、`/colorTransfer`、`/colorPicker`、`/aiAgent`、`/requirementAnalysis`、`/bestSeller`、`/designCanvas`。

## 通用复用模板

### 商品设计 brief

```text
对象：{产品或品类}
目标：{单品/系列/电商套图/趋势企划}
必须保留：{造型、尺寸关系、结构、图案、材质、品牌识别}
允许变化：{颜色、背景、配件、姿态、场景}
风格：{趋势/市场/受众/情绪/参考}
输出：{数量、比例、白底或场景、是否需要文案/3D/线稿}
验收：主体完整，文字可读，结构合理，系列一致，无遮挡和明显变形
```

### 提示词四段式

`主体与产品关系` + `必须保留项` + `允许变化项` + `画面与验收标准`。
先写不可变约束，再写创意方向；出现多张图时用“第 1 张/第 2 张”明确引用。

示例：

```text
以第1张图的陶瓷杯为主体，保持杯口、把手比例和釉面质感不变；把第2张图的
海浪纹样应用到杯身，纹样边缘自然贴合曲面；白色摄影棚背景，正面三分之二视角，
单品居中，避免新增文字、变形把手或改变产品数量。
```

## 权重化决策示例

先看输入图片数量和用户目标，再看是否命中专用工具：

| 需求信号 | 工具 | 可直接复用的提示词 |
| --- | --- | --- |
| 一张杯子，换釉色但保留器型 | `variation` | `只将釉色改为雾霾蓝，杯口、把手、比例、光影和拍摄角度保持不变` |
| 一张包，做同系列新品 | `extend` | `保持原包的提手、缝线和材质语言，延伸同系列电脑包，增加独立收纳层` |
| 产品图+趋势页+色卡 | `mix` | `第1张提供产品结构，第2张提供趋势主题，第3张提供配色，融合成可量产新品` |
| 一张基准图，指定春夏趋势，只要一张设计图 | `variation` | `沿用基准图结构，吸收春夏轻户外趋势，生成一张设计图，保留品牌识别细节` |
| 两张图但只想改第一张颜色 | `variation` | `以第1张为唯一主体，只改为暖橙色；第2张不作为参考，不新增产品` |
| 没有图片，只说“设计一款茶壶” | `imagegen` | `透明锤纹玻璃茶壶，木质把手，内销春夏，白底产品摄影，结构可生产` |
| 图案+帆布包产品图 | `pattern-apply` | `图案线条、颜色和重复关系不变，自然贴合第2张帆布包，包体版型不变` |
| 产品图+围巾/帽子辅料 | `material-product` | `产品造型不变，将第2、3张辅料应用到产品，尺寸协调，不遮挡关键结构` |
| 产品图要电商 7 张图 | `product-kit` | `亚马逊美国站英文 1:1，突出防水和容量，输出主图、场景、模特、细节和卖点图` |
| 只换白底为自然场景 | 更换背景 | `主体边缘完整，换成春日窗边自然光和浅木桌面，接触阴影真实` |
| 要横向海报留白 | `outpaint` | `向左右扩展为 16:9，保持主体大小和位置，补充同风格背景，不裁切主体` |
| 产品图套用另一张色彩 | `color-transfer` | `保留第1张产品结构，仅参考第2张的综合色彩和明度关系，输出 4K` |
| 低清人物图变清晰 | 高清修复 | `保留人物五官、衣物和背景关系，修复细节，不改变姿态和服装颜色` |
| 产品图做结构线稿 | 线稿提取 | `输出精细黑白结构线稿，保留轮廓、缝线和孔位，去掉阴影和背景` |
| 一张图转 3D 可编辑模型 | `image-to-3d` | `保留产品外轮廓和比例，生成可编辑模型，输出 GLB；补充多视图时按视角标记` |
| 商品图做短视频 | `video` | `@1 产品保持形态不变，镜头从正面缓慢环绕，展示材质高光，8 秒，16:9，普通模式` |

反例：用户说“只提取图案”不要选 `variation`；用户说“只放大 4 倍”不要选
`extend`；用户给 3 张图但没有融合意图时不要默认 `mix`，先问每张图的角色。

## 首轮极速路径

单张基准图且用户要一张设计图时，不做额外方案推测，直接套用：

```text
已验证的图片 URL（或本地图片 upload/check）
  -> variation
  -> modelChannel=2, batchSize=1
  -> 同一命令 --wait-seconds 120 --no-progress
  -> 交付一张结果
```

输入复用优先级为：当前会话已检测的公开 HTTPS URL、之前成功上传并检测的 URL、
最后才是新的本地 `upload`/`check-image`。标准路径不调用搜索、趋势详情、知识库、
浏览器、需求解析 Agent、文档工具或布局拼接，也不要求用户先确认一份企划方向。

提示词固定按四项组织：

```text
主体与必须保留：{结构、比例、主体、品牌识别}
允许变化：{用户明确要求的颜色、材质、细节或主题方向}
画面要求：{背景、视角、构图、质感、文字可读性}
输出：只生成一张完整设计图，不拆分、不追加其他方案。
```

如果用户只说“参考这张图做一张设计图”，直接使用：
“保持主体结构和主要视觉特征，按用户目标生成一张设计图；画面完整、结构清晰，
只输出一张完整图片。”不要为了补充细节而启动搜索或多轮确认。

“趋势”“主题”“企划案”本身不等于搜索、系列或文档授权。用户给出的趋势词和主题词
直接写入 variation prompt；只有用户明确说“搜索趋势/找参考/按报告依据”“做同系列/延展”
或“写企划文档/分析报告”时，才切换增强流程。

## 客户反馈后的下一轮

| 客户反馈 | 下一步 |
| --- | --- |
| “不满意/不太对/不合适”，没有具体方向 | 只询问要改的内容，不创建收费任务 |
| 明确改颜色、材质、结构细节或画面 | 基于当前结果再调用一次 `variation`，仍一张、模型二 |
| 明确“再来一张/再出一版” | 调用一次 `variation`；没有新方向时复用上一轮 prompt，不得自动批量生成 |
| 明确“继续延展/做同系列多款” | 才调用 `extend` |
| 明确“融合这些图片/做宫格或联图” | 才调用 `mix` 或用户指定布局工具 |

每个新增收费任务都必须对应当前轮次的明确请求；等待超时只查询原 task ID。

## 生成与系列

### 分身生图 `/GenerateAI`

- 仅在用户明确要求 IYW 分身或多平台比稿时使用；普通纯文生图、动漫和人物形象优先 `imagegen`。
- 适合纯文字创意、多个分身比稿和无基准图种子设计。页面有提示词、导入图片自动推理、帮写/优化、创意拓展、图片比例和生成数量。
- 普通请求只用一个实时可用分身，优先通道四；只有用户说“比稿/多平台”才 `--compare-platforms`。
- 有基准图且首轮只要一张设计图时先 `variation`；只有明确要同系列或延展多款时才用 `extend`。不要让 agent 猜模型 ID、平台、size 或 stats。
- 示例：`“为 2027 春夏内销设计一组透明锤纹玻璃茶壶，木质把手，现代东方风，白底产品摄影”`。

### 自定义改款 `variation`

- 输入 1 张图；首轮固定 1 张、`modelChannel: 2`，使用标准模板同命令等待结果。
- 提示词写“改什么 + 不改什么”：`“只把包身改成深绿色防水尼龙，保留版型、拉链、提手和视角不变”`。
- 一张基准图的企划案请求直接要求“生成一张完整企划案版面图”，不创建前置文档。
- 不适合只想放大、抠图、改背景或转换格式的请求，改走对应专用工具。

### 系列延伸 `extend`

- 输入基准图；先说明系列产品、共同语言和变化维度。页面默认 1 张，模型和比例可选。
- 示例：`“保持原图的圆角轮廓、蓝白配色和磨砂陶瓷工艺，延伸同系列花瓶、托盘、香薰座各一款，先输出花瓶”`。
- 有趋势素材时把已验证的趋势事实写入提示词，不把整份报告原文塞进去。

### 多图融合 `mix`

- 2-10 张，顺序有意义；先说明每张图承担的角色，默认 1 张和 `modelChannel: 2`。
- 示例：`“使用第1张的产品结构、第2张的水果主题、第3张的配色，融合为一件可生产的陶瓷餐盘；保留结构清晰、无多余产品”`。
- 不同主题的素材不要混成一组；每个主题单独形成种子，再用 `extend` 做系列。

### 显式增强的边界

- 只提到趋势或主题：把词语作为 prompt 方向，仍按单图极速 variation。
- 明确要求搜索趋势、参考图、报告或知识依据：先走对应搜索/知识流程，再按用户选择生成。
- 明确要求企划文档、分析报告或文字方案：进入文档/Agent；“企划案版面图”仍是图片任务。
- 不满意但未说明如何修改：先问一句，不把反馈当成自动重跑授权。

## 产品与商业场景

### 图案应用 `pattern-apply`

- 选择图案和产品，先标明“图案不变/产品可变或不变”；页面也支持搜索爆款图案。
- 示例：`“保持图案线条、颜色和重复关系不变，完整应用到第2张帆布包，包体结构不变，边缘自然贴合”`。

### 配辅生款 `material-product`

- 选择已有产品、1-5 个配件/辅料，并明确产品能否改变；页面默认 `isChange=0`（不改变产品）。
- 示例：`“产品造型不变，把第2张围巾和第3张帽子的红色织物应用到玩偶，配件尺寸可微调但不可遮挡五官”`。

### 自由仿款 `free-imitation`

- 适合参考图驱动的自由变款；页面有控制类型、参考权重、比例和原图比例。
- 先说明参考权重意图，不把“参考权重 5”当成所有接口都通用的数值。示例：`“保留构图和品类，重新设计成可量产的春夏款，避免复制品牌标识”`。

### IP 应用 `ip-apply`

- 先选已授权 IP 或上传授权素材，再选产品；页面明确提示仅作效果展示，实际使用需获得授权。
- 示例：`“将已授权角色置于产品正面，保持角色比例和识别特征，设计儿童水杯包装，避免新增未授权角色”`。

### 商品套图 `/product-kit`

- 最多 3 张同一产品原图；设置电商平台、国家、语言、比例。可选智能匹配或自定义配置，至少 7 张；可附加爆款风格分析和商品上架文案。
- 7 张基础结构按“主图白底、场景展示、模特场景、细节说明、卖点详解”等组织；平台规范优先于审美偏好。
- 示例 brief：`“亚马逊美国站，英文，1:1；不改变产品结构，突出防水、容量和收纳分区；输出 7 张套图及上架五点描述”`。

### 模特场景与 AI 试衣

- `model-scene` 支持最多 10 张产品图，比例自动/1:1/4:3/3:4/16:9/9:16，分辨率标准或高清。
- `AI 试衣` 使用服装图和模特/场景要求；内衣泳衣选择专用模型。示例：`“保留衣服版型、面料纹理和颜色，生成自然站姿的半身电商图，纯色背景”`。
- 有人脸、版权或敏感素材时先确认授权和平台限制，不以“生成成功”替代合规检查。

## 编辑、版式与输出

### 涂抹编辑与指令编辑

- `edit`/涂抹编辑要上传原图和 mask，选择“编辑”或“消除”；提示词只描述选区要重绘的内容。
- `instruction`/指令编辑适合整图语义修改：`“只把背景改为浅灰棚拍，主体大小、角度和阴影保持不变”`。

### 背景、扩图、融合

- 更换背景支持单图和多图模式；提示词写背景、主体、场景、氛围四项。示例：`“春日窗边自然光，浅木桌面，主体接触阴影真实，保留产品边缘完整”`。
- 智能扩图先选原始比例或 1:1、2:3、3:2、4:3、16:9、9:16，再描述扩展方向；扩图不是裁切。
- 智能融图 `blend` 不要求提示词，适合两张图直接融合；需要控制主次时改用 `mix` 并写清引用关系。

### 放大、修复、增强

- 无损放大：2-8 倍，模型一支持更大尺寸，模型二适合新模型效果；输入过大先确认限制。
- 高清修复：2 倍或 4 倍，适合人像/模特细节；画质增强用于整体观感，不替代印刷细节放大。
- 选择依据：印刷/纹样细节 -> 无损放大；低清人像 -> 高清修复；整体质感 -> 画质增强。

### 图案、线稿、色彩

- 提取图案：可选平铺、形状、透明底；清晰度可选标清、2K、4K。提示词必须写“去除产品结构，只留平面图案”。
- 二方连续/图案循环：输入单张图，分别用于左右连续或更完整的循环平铺。
- 线稿提取：粗略/精细；线稿渲染和画单线图再补充材质、线宽、用途。示例：`“输出精细黑白线稿，保留结构轮廓和缝线，去掉阴影和背景”`。
- 配色迁移：必须有产品图和参考图，可选 2K/4K；提取色号可选潘通、三山、劳尔色。

### 格式、3D、视频、出血线

- 格式转换支持 PSD、SVG、BMP、GIF、ICO、JPEG/JPG、ODD、PNG、TIFF、WebP；先确认输入格式和下游软件。
- 3D 单图可补充左/右/顶/底/前后多视图，格式包括 GLB/USDZ/FBX/OBJ/STL（部分页面另有 3MF）；多视图必须按视角标记。
- 图转视频：素材可为图片/视频/音频，提示词用 `@1`、`@2` 引用；比例支持 16:9、9:16、4:3、1:1、3:4、21:9，时长 4-15 秒，普通/高清模式。人脸露出素材受限制。
- 出血线：上传 PNG/JPG/WebP，单张不超过 50MB、最长边不超过 3840px；主体检测或透明通道，设置毫米/厘米、虚线/实线、白底/透明/棋盘格，导出 PNG 或 SVG。

## 搜索、知识与历史

- 趋势设计：只有用户明确要求搜索或报告依据时才先 `trend-list`/`trend-detail`，再 `image`（趋势图片 `classify=[51]`）；仅有趋势词的单图请求仍按 variation，搜索无结果时不得凭空收费生成。
- 知识库：企业标准、材料工艺、品牌/IP 手册、结构和合规约束先查 `iyw_knowledge.py`；只提炼与本任务有关的约束。
- AI Agent `/aiAgent`、需求解析 `/requirementAnalysis` 和电商 Agent `/bestSeller`：可上传 PDF、PPT、DOCX、TXT、CSV、XLSX、图片和 SVG；先让 Agent 提取产品、数量、材质、市场、背景和交付格式，再选择工具。
