## 登记清单

提交前为每张证书准备一行清单，至少包含：

| 字段 | 要求 |
|---|---|
| 客户 | 必须与当前登录公司一致 |
| 作品名称 | 非空；同批次内检查重名 |
| 作品文件 | 每证 1–6 个明确分组的图片 |
| 发表状态 | `未发表` 或 `已发表` |
| 创作起止时间 | `yyyy-MM-dd`，开始不得晚于完成 |
| 创作地点 | `国家/省/市` 三级地址 |
| 权利归属 | 个人作品或法人作品，由材料决定 |
| 权利保证书 | 每证一份，并在本次登记重新上传 |
| 发表信息 | 已发表时必须有时间、三级地点和凭证 |

不要仅凭文件位于同一客户目录就推断“每图一证”或“多图一证”。分组不明确时必须先确认。

## 固定字段合同

| 页面字段 | 内部值 | 含义 |
|---|---:|---|
| `creationType` | `1` | 美术作品 |
| `classify` | `"0"` | 美术作品分类 |
| `publishStatus` | `1` / `2` | 已发表 / 未发表 |
| `creatNature` | `1` | 原创 |
| `rightsWay` | `1` | 原始取得 |
| `rightsBelong` | `1` / `3` | 个人作品 / 法人作品 |
| `copyrightInfo` | `1..17` | 全部 17 项著作权 |

`rightsBelong=3` 仅适用于法人作品，且著作权人和作者应与企业材料一致。遇到合作、职务、
委托作品或不是全部 17 项权利的申请时，当前内置提交脚本不适用；停止并要求确认或扩展合同。

`modelForm` 位于 `v.$refs.model._data.modelForm`，不是 `v._data.modelForm`。登记模板保持
`templateId=null`；不要猜测或套用未知模板。

## 文件限制

| 上传区域 | 限制 | 组件 |
|---|---|---|
| 作品文件 | 最多 6 个；单文件不超过 20 MiB，累计不超过 1 GiB | `input.fileInput` |
| 展示图片 | 最多 6 张；每张小于 5 MiB | 系统从作品图片自动生成 |
| 发表凭证 | 1 个 | 标签区域内的 `input.fileInput` |
| 权利保证书 | 1 个 | `.getImgContainer` 的 drop 处理器 |

当前流程只接受 `.jpg`、`.jpeg`、`.png` 和 `.webp`。图片宽或高不得超过 10000 px；CMYK
图片先转为 RGB。生成的 base64 JavaScript 含原文件内容，执行后立即清理。

## 已发表作品

已发表作品必须同时满足：

1. `publishStatus=1`。
2. `publishTime` 为真实首次发表日期。
3. `publishArea` 为真实的国家/省/市三级地址。
4. 发表凭证上传成功，`productPubAnnex` 至少包含一个有效条目。

未发表作品固定使用 `publishStatus=2`，不得为了通过校验虚构发表日期、地点或凭证。

## 单证多图

- 最多六张，按清单顺序逐张上传，每张等待 OSS 完成后再传下一张。
- 不要生成一个包含多张图片 base64 的超大 eval 脚本；大脚本可能被命令解析器截断。
- 全部作品为受支持图片时，系统应自动生成同数量展示图。
- 提交预检要求 `workFileLen` 与 `showFileLen` 相等，且数量与清单一致。
- 任何一张上传失败时停止当前证书，不得用缺图结果提交。
