# 故障排查

按“页面状态 → 上传状态 → Vue 字段 → 提交结果”的顺序检查。不要在结果不确定时重复提交。

| 现象 | 原因 | 处理 |
|---|---|---|
| 无法导入 `openpyxl` | 当前 Python 环境缺依赖 | 在隔离环境安装 `openpyxl`，不要改系统 Python |
| 登记页显示登录页 | 浏览器会话失效 | 让当前操作人完成登录，再核对客户公司名 |
| 普通 upload 无反应 | 作品区是隐藏自定义组件 | 使用 `build_upload_js.py --kind work` |
| 上传后父表单无图片 | 父组件未即时同步 | 检查 `wirksFile.fileList`，不要手填 OSS URL |
| 提示未选择作品分类 | `classify` 为空 | 确认提交脚本已调用 `selectType` |
| 提示未上传保证书 | drop 事件发错元素或上传未完成 | 重新检查 `.getImgContainer` 和页面“重新上传”状态 |
| 保证书进入其他附件 | 错投到 `el-upload__input` | 删除误传附件，重新用 `--kind guarantee`；未确认清理前不提交 |
| 字段赋值不生效 | 使用了错误的 `modelForm` | 使用 `$refs.model._data.modelForm` |
| 提示未勾选须知 | `readed` 或 `guarantee` 未设置 | 重新执行 inspect 并核对结果 |
| 页面无响应 | 表单校验、网络或提交仍在进行 | 等待并 snapshot；不要再次调用 submit |
| 第二件找不到上传框 | 仍在成功页 | 点击“继续申请版权”并等待登记页加载 |
| `getFileList(1)` 为空 | 站点组件参数处理问题 | 仅使用内置提交脚本的已知补丁，不另写绕过逻辑 |
| 展示图数量不一致 | 自动提取未完成或失败 | 等待并重新 inspect；数量不相等时不提交 |

## 误传其他附件

只有页面结构仍与已验证版本一致时，才从已缓存组件移除误传项：

```javascript
const v = window._dbg;
for (const item of [...(v._data.form.otherAttachements || [])]) {
  v.removeDragFile(item);
}
v._data.dragFiles = [];
v._data.previewList = [];
```

执行后必须重新 snapshot 和 inspect。找不到 `window._dbg`、方法或字段时停止，不猜测替代名。

## 暂存回退

`submit(0)` 也会创建外部记录。只有用户明确同意暂存时才采用以下回退：先暂存，到管理页
确认产生唯一“待提交”记录，进入编辑页后重新上传缺失附件、重新 inspect，再提交一次。
不要把暂存作为提交不确定时的重试手段。

## 必须停止的情况

- 登录客户与清单不一致，或剩余登记件数不足。
- 页面字段、选择器、Vue 引用或成功文案发生变化。
- 合作、职务、委托作品，权利项不是全部 17 项，或材料之间权利归属不一致。
- 作品、展示图、保证书或已发表凭证缺失。
- 页面显示提交处理中、网络中断或提交结果不确定。
- 管理页出现同名待提交或审核中记录，存在重复风险。
