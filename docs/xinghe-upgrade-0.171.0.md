# 星河内核 0.171.0 升级记录

2026-11-20，内置星河从 0.169.0 升至 0.171.0。官方标签对象为 `295eca93394bb83a6ec8e0841033f3997f97fcbd`，源码提交为 `ccf9be8cc458bd6b8336fe84d68d8893f2691a5e`。[官方发布](https://github.com/openai/codex/releases/tag/rust-v0.171.0)

## 宿主适配

- MCP 使用服务名称和环境标识区分注册项。线程状态查询从已发布的连接读取工具和资源，分页保留环境标识。内置 MCP 继续走进程内通道。
- 托管附件按上游的新类型区分图片和工具音频。图片沿用网关查重、上传和内容校验，工具音频交给既有附件存储。压缩沿用宿主请求预算，保留托管图片引用和摘要。
- 上游图片处理固定使用 `image 0.25.9`，Office 预览需要 `0.25.10`。图片处理覆盖包引用 0.25.9 发布包记录的源码提交 `5ceb6af6c2b6671931a02fda955ce1676321711d`，Office 依赖继续从 crates.io 解析。
- 同步三个官方 SQLite 迁移，分别建立会话模型标识表、调整会话列表索引和添加实时历史查询索引。源码升级和本机验证仅读取迁移文本。

## 验证

- 官方标签和提交回读与 `upstream.lock` 一致。运行时资源准备脚本生成 0.171.0 的进程内运行时标识。

- 81 个 SQL 文件与上游按统一换行对比一致，35 处嵌入资源引用均可解析。协议导出保留可选命令描述与压缩摘要。
