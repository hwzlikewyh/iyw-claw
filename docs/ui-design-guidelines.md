## 规则摘要

| 编号 | 设计与实现要求 |
| --- | --- |
| S1 | 矩形转角采用连续曲率；使用 `corner-shape: squircle` 时保留 `border-radius` 回退，并核对实际浏览器支持。 |
| S2 | 嵌套圆角同心：内圆角 = `max(0, 外圆角 - 内边距)`，不对所有层使用同一半径。 |
| S3 | 先设计窄态保留的信息，再调整宽度；窄态仍可完成核心任务。 |
| S4 | 收起时先隐文字、再收窄；展开时先给宽度、再显文字，避免中途换行与挤压。 |
| S5 | 导航可收成图标栏；阅读型详情整块收起，关键字段移到内容标题处，控制入口保持固定。 |
| S6 | 层级主要靠明度表达；灰阶组织信息，整屏只保留一个高饱和强调色。 |
| S7 | 先安排元素让位和进场顺序，再调缓动；反馈可打断，不在过渡中抢焦点。 |
| S8 | 网格与数值对齐后，再核对图标、文字、圆形和角标的光学基线。 |
| S9 | 默认态静止，状态变化才反馈；尊重 `prefers-reduced-motion`。 |
| S10 | 多级菜单根据指针向子菜单移动的区域保护当前菜单；锥内避免沿途误切，锥外及时切换，仅对歧义停留使用约 300ms 延迟，保留键盘与触控操作。 |
| S11 | 深色主题使用近黑底、柔和白字、逐层提亮表面与细边框，强调色适当变浅；次要文字对比度至少 4.5:1，色值统一使用主题变量。 |

深色参考：背景 `#121418`，正文 `#E6E8EC`，表面逐级使用 `#1B1E24`、`#252931`。这些是原文示例，不代表当前产品已完成全局适配或对比度实测。

## 本次连接器修复的落点

- 输入框不显示已选连接器标签，通过“＋ → 连接器”管理对话选择。
- 点击菜单开关时维持菜单焦点；编辑器的空白区聚焦逻辑不处理 Portal 中冒泡的鼠标事件。
- 复用 Radix 的菜单选择、指针容错区域、键盘与触控行为，不新增一套菜单状态或统一延长悬停等待。
- 当前修改没有调整全局主题、圆角或动效；后续涉及这些区域时再按对应规则实施。
