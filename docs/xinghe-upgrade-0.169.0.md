# 星河内核 0.169.0 升级记录

日期：2026-11-17。

## 目标与验收

内置星河从 0.167.1 升至官方稳定版 0.169.0，继续沿用进程内运行时和 ACP 桥接。
应用版本与已安装程序由后续构建发布更新，本次仅交付源码升级。

1. 官方标签、源码提交、生产依赖与内置身份一致。
2. 保留宿主认证和环境、进程内 MCP、托管图片、命令描述、消费归属、请求预算及
   Windows/Win7 补丁。
3. 通过依赖解析、独立 harness 类型检查、资源和协议检查及静态审查。
4. 只提交升级相关文件，推送到两个远程地址并合入各自的 `main`。

## 执行计划

## 迁移决策

22 个本地覆盖包继续固定官方源码提交。保留宿主凭据和环境投影、同进程 MCP、
已发布 MCP 连接查询、托管图片引用与工具输出图片、命令说明、压缩摘要、消费回执和
Windows 沙箱的同 EXE helper 分流。

采用上游新的响应项 ID 分配、音频拒绝记录、原始历史读取、MCP 刷新原因及取消恢复、
沙箱变换接口、模型供应商接口和 SQLite 迁移事务边界。本地 LF/CRLF 迁移校验兼容
继续在迁移事务前建立；不打开用户数据库、不执行迁移 SQL。

压缩继续共用本地请求预算、网关超时重试和托管图片恢复。重试等待采用上游的
`RetryAfter`/错误退避信息并受本地预算限制；上游的待处理消息保留与本地摘要字段共存。
耗时投影将上游 sampling 与 compaction 合并为既有推理类别，保持宿主数组布局。

使用上游要求的 SQLx Core/SQLite 固定补丁以支持 `libsqlite3-sys 0.39`，同步
WebSocket 补丁提交；生产图不使用 V8，未引入其源码覆盖。`codex-feedback` 与
`codex-core-plugins` 的 `tar` 继续固定
0.4.46，与应用现有 Qdrant 依赖一致。保留 PTY 的 HANDLE 类型转换和隐藏窗口补丁。

稳定/实验协议资源以 0.169.0 官方导出为基线重建，分别保留 20/24 组可选命令描述和
压缩摘要定义。精简支持模块、原有内部同步工具及其路径别名继续按生产覆盖约定保留。
