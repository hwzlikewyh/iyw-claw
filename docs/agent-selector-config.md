# Agent 选择器配置

所有 Agent SDK 的会话选择器通过 `getFixedAgentOptions()` 同步构建：

- `src/lib/agent-control-profiles.ts` 定义各 SDK 的权限模式、协作方式、推理和速度配置 ID。
- `src/lib/gateway-model-catalog.ts` 将当前 SDK 的模型目录与上述配置合成选项。
- `src/lib/gateway-model-store.ts` 同步读取本地目录缓存，在线更新由已有后台请求完成。
- 会话、自动化和委托设置复用这一配置来源。

## 显示边界

模型按钮、列表和草稿选中值直接使用 `fixedOptions.config_options`，不得等待
`conn.selectorsReady`，也不得与 `conn.configOptions` 取交集后再展示。
ACP 没有连接、尚未上报模型或仍使用旧目录时，均不影响已加载配置的显示。

首次使用某个 SDK 且没有目录缓存时，仍需取得该 SDK 的在线目录；不得使用其他
SDK 或未经筛选的通用目录冒充其配置，也不恢复过时的硬编码模型列表。

悬停模型的思考强度、快速模式和上下文窗口直接通过该模型的目录配置生成，
不得以当前选中模型的选项作为模板。当前模型未启用快速模式时，悬停其他
启用该能力的模型仍显示快速模式。菜单底部不再提供“模型配置”入口。

自动压缩阈值显示后台 `limits.compaction_threshold_percents` 允许的百分比，
客户端不生成固定档位；空列表只展示自动。自动沿用后台默认压缩策略，手动
比例按当前窗口计算并受输出预留和输入上限约束。

## 执行边界

提前选择只更新当前会话草稿。新建或恢复会话的初始化回填不得覆盖尚待应用的手动选择。
Agent 就绪后通过既有配置同步与模型重载流程应用选择。实际发送继续检查连接与模型确认，
会话模型仅在 Agent 确认后持久化；目录显示不代表模型已经应用。

预热、连接启动和重连传入当前对话草稿配置，优先于全局偏好。模型确认之后仍保留
用户手动选择标记，首次发送创建会话记录的历史回填不得将其覆盖为默认模型。
应用失败保留所选模型并提示重选，确认前阻止发送；不会静默改用默认模型。

## 配置生效时机

存活的会话保留启动时的配置和上下文预算。保存 Agent 设置或刷新模型目录时，
不弹出重连提示、不阻止发送，也不因 Auto 额度或可选档位变化自动重启会话。
重新打开仍然存活的对话复用原连接；只有原连接被回收后恢复或新建对话时，
才通过既有启动入口读取最新配置。预热会话仍按当前配置指纹校验，过期预热不复用。

用户在当前会话主动切换模型、思考强度或上下文档位时，继续走原有应用确认流程；
需要重建运行时的手动操作保留。启动参数中的模型目录和预算快照仍用于隔离不同配置，
运行中会话不会与全局默认配置比较并被误判为必须重连。

上下文窗口与自动压缩阈值按 Agent 和模型保存；开始对话后仍可修改，当前回复
结束后通过既有重载入口应用。同一次预算更新同时携带窗口与阈值，失败回滚两项。

已由 Agent 确认的当前模型即使不再出现在最新目录中，也不在本地拒绝发送；
由请求后端判断实际可用性并返回错误。手动切换仍等待模型确认，避免以其他模型执行。
