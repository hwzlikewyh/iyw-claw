## 迁移决策

对 0.166.0 官方源码、本地覆盖和 0.167.1 官方源码做三方迁移，更新 22 个生产覆盖包。
保留宿主认证和环境、进程内 MCP、已发布连接查询、命令描述、托管图片、压缩预算、
任务消费归属与 Windows/Win7 补丁。采用上游 MCP 连接租约、网络审批取消与串行化、
子线程继承执行策略及新的工具元数据接口。

历史计量保留本地代际与计数来源校验，同时采用上游失败响应计量边界：有有效 usage
时更新覆盖位置，失败或无 usage 的输出继续估算。恢复记录仍不能证明计量覆盖关系，
上下文满额状态同步更新覆盖位置，避免将旧位置误认为当前历史的计数。

新版 `InProcessClientStartArgs` 增加 `required_human_approval`。现有 ACP 桥接没有
实现 `humanCommand` 的一次性人工审批协商，因此设置为 `false`；此类托管策略命令
沿用上游无兼容客户端时的拒绝路径，不复用普通审批或自动审核结果。

固定官方源码的 `guardian/recorded_tool_call.rs` 仍无参数调用 `direct_source`，与
同版本接口不匹配。补齐当前线程的多智能体工具命名空间，与正常工具执行路径一致。
本地压缩失败路径沿用上游处理方式，显式忽略保留输入 hook 的返回值并返回原压缩错误。

稳定及实验协议资源从新版官方导出重建，保留可选命令描述和压缩摘要；未加入测试文件。
78 个原生迁移 SQL 与官方源码一致；本次没有打开运行数据库或执行迁移。
