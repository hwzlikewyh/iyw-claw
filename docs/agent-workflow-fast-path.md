# 通用 Agent 工作流程提速：第一批

2026-10-28。本批减少普通任务的额外实验、目录读取的保守串行和多轮对话的 UI 指南重复注入。
使用现有宿主、MCP、原生会话和日志，不增加任务总轮数、费用或耗时限制。

## 行为变化

- 通用提示要求独立读取、计算和检查尽量批处理，保留失败和输出引用；有依赖的操作与冲突写入保持顺序。
- 使用 Skill 本身不再触发改进实验；用户明确要求，或当前已授权任务确需解决反复出现的问题时，仍沿原流程改进和验证。
- `search_iyw_capabilities`、`read_iyw_capability` 标为只读、非破坏性，保留开放世界提示。通用 invoke、记忆和写工具没有放宽。
- 星河、远山的同一连接内，携带完整 UI 指南的回合正常结束后，后续普通输入改用精简说明。
- 每次仍读取 UI 开关和当前用户状态；精简说明包含启用声明、格式版本、完整技能入口及数据/授权边界。

只读 annotations 供运行时判断多个独立调用是否可以并发，不保证模型会同时请求这些调用，也不绕过宿主权限、限流或取消。

## UI 指南复用条件

`ui_guide_delivery.rs` 只保存当前原生会话和待确认的回合代次，不写数据库，不序列化到前端。
完整指南在原生回合 `end_turn` 后才确认；单纯入队不代表已经送达。选择完整/精简在最终入队门禁内完成，没有额外异步等待。

| 情况 | 下一次普通输入的处理 |
| --- | --- |
| 新连接、恢复旧会话、会话重新绑定 | 完整指南 |
| 同一原生会话成功完成完整注入回合 | 精简说明，保留当前 UI 状态 |
| 标准压缩元数据、原生压缩摘要或远山 `compact_boundary` | 清除复用状态，重新补齐 |
| 上下文用量下降或历史内容恢复 | 保守清除复用状态 |
| 异常结束、断线、终止性错误 | 清除复用状态 |
| `/clear`、`/compact` 等以斜线开头的控制输入 | 保守清除，不把命令成功当作指南已接收 |
| 观察到 UI 关闭或设置不可用 | 只发送原有关闭/不可用通知，并清除复用状态 |
| 其它运行时，或上下文已达到压缩阈值 | 继续完整注入 |

指南由 `include_str!` 随应用版本编译，进程更新会自然重置连接内状态。没有引入跨版本持久缓存。
如果精简后的会话已经缺少完整语法，提示要求读取已安装的 `ui-render` 技能；不可用时使用 Markdown，不猜测组件能力。
运行中的原生自动压缩仍由运行时管理；本批不插入额外模型回合。完整指南的重新注入发生在下一次宿主正常提交输入时。
原有用户记忆、任务续接、原生后台任务和真实权限不因本批改变。

## 观测与比较

在已有 `[ACP] prompt enqueued to connection command channel` 日志追加：

| 字段 | 含义 |
| --- | --- |
| `ui_guide_mode` | full、reused、disabled、unavailable 或 absent |
| `ui_prepare_ms` | 本次 UI 设置/状态准备耗时 |
| `ui_context_bytes` | 本次 UI 私有上下文的 UTF-8 字节数，包含状态与 envelope |
| `ui_guide_saved_bytes` | 相比同一完整指南，本次省去的注入字节数；只有 reused 非零 |
| `context_bytes` | 入队的宿主 user_context 字节数，不是最终模型全部输入 |

日志不包含指南正文、UI 数据、用户消息或凭据。新增字段附在原有每次入队日志上，不增加轮询。

```powershell
node scripts/analyze-agent-startup.mjs <before.log> <after.log>
```

分析结果新增 `promptPreparation`（准备耗时）与 `promptContext`（字节统计），按应用版本、Agent 和指南模式分组。
旧日志缺少字节字段时不产生该项样本；指南模式为 unrecorded，不把缺值当成 0。
`totalBytes` 是日志样本总量，包含未最终完成的已入队输入，不等于模型收费或网络净流量。
结合原有 turnLatency 和实际交付验收比较完成耗时；不同任务、模型或环境不直接比较百分比。

## 本轮验证与边界

- 静态审查覆盖 search/read 的本地目录、插件、渠道和远程元数据路径，及 UI 输入、正常/异常终态、会话身份、压缩和恢复分支。
- Rust 使用已安装 stable 工具链的 rustfmt 做语法解析，旧大文件仅输出到空设备，不格式化无关内容；未运行类型检查或链接。
- 日志分析脚本通过 Node 语法检查，并读取 2026-10-27 的 48,414 行历史日志，JSON 解析失败为 0；新增缺省字段兼容旧记录。
- 本地源文件计量：完整 GUIDE 为 6,428 字节，精简正文为 514 字节，复用一次少注入 5,914 字节（换行格式不同的平台以实际日志为准）。

按仓库规则没有新增或运行测试，没有构建、打包、启动桌面或调用收费模型。
还需在发布允许的环境验证真实新建/恢复/压缩/关闭再开启会话、两引擎并发行为及最终完成耗时；字节减少不能当作已获得相同幅度的速度收益。
