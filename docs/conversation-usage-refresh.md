# 会话用量按需刷新

输出中的本轮统计与会话用量面板，共用按后端 Transport 和会话 ID 隔离的读取器。
原有每次完成后等待 1 秒/3 秒的完整历史轮询已移除。

## 刷新来源

- 沿 ACP 已有事件分发路径接收用量更新、工具完成/失败、回合结束及会话恢复信号。
- 远山原生消息的 assistant/result 作为兼容刷新信号；后台活动仅在有实际历史或完成项时触发。
- 正文、思考增量不刷新历史。首次订阅、页面重新可见和传输重连补读一次。
- 250ms 合并相邻信号，同会话最多同时一个读取，启动间隔至少 1 秒。在途更新合并为一次后续刷新。
- 终态后 1.5 秒补读一次，以容纳原生日志延迟落盘；请求失败或点数暂缺时最多额外重试一次。
- 隐藏页面停止读取，所有订阅移除后清理定时器和快照。新会话/新回合使在途旧结果失效。

## 统计与兼容

继续使用既有 get_folder_conversation、历史解析器和点数估价，不新增后端接口或字段。
上下文事件中的 used/size 仅作为刷新信号，不能当作分类消费 Token。

本轮用量仅在后台已关联 in_flight_user_turn_id 后显示；尚未关联时保持等待，避免将
上一轮消费展示在新回复上，也避免使用远程客户端时钟判断服务端历史的时间。
跨页时检查外部会话、当前用户边界、历史条数和累计 Token 一致性，变化时放弃部分结果。
只打开会话面板时读取尾页统计，不为本轮用量额外翻页。完成后的统计仍沿既有历史同步补齐。

读取完成仅保留轻量用量快照，不缓存完整正文和工具输出。旧运行时缺少用量更新事件时，
工具和回合结束仍会更新；不承诺流式输出中的每个 Token 都有消费统计。

## 验证与限制

按仓库规则进行静态审查、TypeScript 无输出检查、定向 ESLint 和差异检查，未新增或运行
测试，未在本机编译、启动或打包桌面端。持续输出速度与真实落盘时序需要发布后验证。
此次消除无变化时的定时读取，并合并两个展示入口；发生用量变化时仍沿用完整历史解析，
不代表所有原生格式都已实现增量解析。
