# 连接器用户发布与直下

能力市场连接器页的“创建 / 上传”和“我的上传”进入独立连接器表单与个人目录。通过既有 transport 调用 `connector_market_user_request`，桌面与 Web 共用 Rust 核心；只向 Fusion `/connector-market/*` 发送当前用户 token。Gateway 和 Fusion 的配套提交分别为 d258a93、314bd91，须部署后才能完成真实云端发布。

表单支持声明导入、多平台、协议与参数配置、制品直传、保存、发布及下架。未保存内容离开前确认；保存失败保留内容；非法声明拒绝导入，非法 JSON 禁止提交。上传完成、保存草稿、公开发布、安装和账号连接各自独立，不把其中一个状态当成全部成功。

技能、插件和连接器下载先向授权接口换取短时票据，然后直接请求对象存储，不给对象请求附带用户 token。连接器下载流式写临时文件并验证大小及 SHA-256，再沿现有原子安装流程激活；保留路径、文件数量及整数检查，不恢复固定包总大小上限。

实机发现的结构化目录错误现使用项目已有错误格式化器呈现，不再显示 `[object Object]`。聚合读取失败继续隐藏不可信总数，并提供重试。

本地验证：18 项聚焦回归、TypeScript 与相关 ESLint 通过；四目录 72 项布局与分页、聚合/连接器 15 项、插件详情/上传 9 场景、侧栏总览 8 项、用户发布 10 项浏览器检查通过。浏览器检查隔离后端与账号边界，不证明真实云端上传或编辑器保存成功。
