# 内置星河的连接器参数

本次修复基于远程 main 的 `4cc0754b73d9023728c1abc1f7b5a59c9d96bd2f`。

## 原因

连接器设置写入受管 catalog 和原生配置文件，但内置星河将原生配置一次性迁移到应用偏好，
启动后不读取用户级配置文件。普通连接器没有再次合入 `CODEX_CONFIG`；同时会话网关使用
整个 `mcp_servers` 覆盖键，又会覆盖已经存在于启动参数中的连接器。

## 配置来源与优先级

1. 应用偏好保留完整星河配置。
2. 每次构造启动环境时，读取当前受管 MCP catalog，覆盖同名受管项，移除禁用项和
   tombstone；非受管项保留。同名旧 `[mcp.servers]` 条目一并移除。
3. 沿用现有 provider、账户凭证、模型、技能预算和提示词投影，生成 `CODEX_CONFIG`。
4. 会话内置网关以 `mcp_servers.<name>` 逐服务器覆盖，保留普通连接器以及其他配置。

投影只读取 catalog，不回写用户偏好，也不在 worker 中恢复用户级配置文件加载。
内置星河安装状态使用实际内置运行器可用性，避免依赖外置 CLI 的版本记录。

| 参数 | 传递路径与边界 |
| --- | --- |
| 模型、推理强度、快速模式、权限/协作模式 | 保留现有完整配置和会话选择器映射、应用确认流程 |
| provider、账户认证、提示词、响应风格、技能、原生插件配置 | 保留现有投影；平台管理字段仍按已有策略覆盖 |
| MCP `command/args/env/cwd` | 经现有原生转换进入完整配置，不走丢弃 `cwd` 的标准 ACP 转换 |
| MCP `url/headers` | 原生转换将 `headers` 映射到 `http_headers` |
| MCP 超时、工具允许/禁止列表、OAuth、环境认证等扩展字段 | 复用原生转换保留非传输字段，最终由锁定内核校验；不承诺支持内核未知字段 |
| SSE | 内置星河不支持；受管启用项会返回明确启动错误，应改用 stdio 或 Streamable HTTP |
| v1 插件 Connector | 与普通连接器共用 catalog 和本次投影 |
| v2 插件 | 继续通过宿主网关动态发现；仍需当前工作区和 Agent 的启用及权限授权 |

`new/load/resume` 都使用当前启动环境，分叉沿用所属 worker 的环境及会话网关配置。
预热/准备会话的配置指纹包含投影后的配置，认领时已有逻辑会拒绝过期准备结果。
运行中的连接不自动重载 MCP；连接器编辑、启禁用、删除，以及市场安装/卸载入口，会复用
现有会话配置陈旧提示。后台自动维护不在此次 UI 提示改动范围内，重建连接后读取当前配置。
