# 任务完成系统通知开关设计

## 目标

在“设置 → 常规”提供一个开关，用于控制用户离开原助理界面时显示的任务完成系统通知。默认开启，保持现有行为；权限请求和 Agent 错误通知继续独立工作。

## 方案

- 使用前端 `localStorage` 保存偏好，避免为一个客户端展示偏好增加 Rust/服务端 API 和数据库字段。
- 在通知完成入口读取同一偏好：普通回合完成和后台任务结算都属于任务完成通知，关闭后跳过；权限请求和错误通知不读取该开关。
- 设置页使用现有常规页的 `SettingSection`/`SettingRow`/`Switch` 组件，并通过自定义事件与 `storage` 事件保持跨窗口同步。
- 桌面与 Web 使用同一偏好读取逻辑；系统通知仍由现有 `document.hidden` 条件决定是否只在用户不在原助理界面时发送。

## 验证

- 静态检查任务完成通知的所有调用入口，确认开关只影响完成类通知。
- 对修改的 TypeScript/TSX 文件运行 ESLint，并执行 `git diff --check`。
- 不新增测试文件；项目规则对本类小范围偏好改动要求定向静态验证。
