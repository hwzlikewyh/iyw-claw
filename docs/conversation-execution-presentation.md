## 用户确认的验收清单（2026-10-23 更新）

1. 思考、过程说明和工具按发生顺序穿插展示。相邻普通操作连续排列，不按每两项或四项插入分组间隔；不拆代码、列表、表格和交互内容。
2. “已完成 + 花费时间”入口只展开/收起本轮中间内容；最终回答及结果作品始终完整展示，不截断、不用一行摘要替代。没有最终正文时仍显示完成状态。
3. 工具显示具体动作与对象，例如“查看 AGENTS.md 文件”“打开 components 文件夹”“搜索 Kimi K3”。复用能力目录解析网关调用，读取嵌套参数；PowerShell 等包装命令展示内部明确的文件或检索动作。实时状态和历史操作复用同一标题逻辑。普通工具不展示原始参数、完整命令、错误正文、JSON 和内部 ID。
4. 有真实来源或摘录的搜索、网页读取可以独立展开详情；没有详情的操作不显示无效箭头。原生权限和提问交互继续由现有交互入口处理。
5. 上下文压缩独立展示，始终保留原有“查看摘要”及摘要弹窗。摘要只来自后端明确标记的保留摘要，不从普通工具输出推测。
6. 复制、分支、模型、耗时、回到提问等底部操作统一靠左；统计紧随其后，窄屏换行后仍靠左，不用两端对齐把按钮推到右边。
7. 点数以普通文字按钮展示，精度固定两位小数（8.133706 → 8.13），悬浮查看详情，支持键盘和触屏。移除“本次消费”、字数、工具次数及“平均输出”四字；保留输出速度数值、首字和首次响应的真实测量值。展示格式不改动账本金额。
8. 初始化、提交环境等技术启动阶段不另铺助手消息；进入模型等待后保留真实等待提示。工具失败只显示失败状态，保留后端日志用于排查。
9. 收纳动画平滑，阅读旧内容、选择文字或操作内容时暂停自动收纳；用户手动展开后保留选择，支持减少动态效果。收纳动画结束后释放隐藏的重内容，避免历史 Markdown 常驻渲染。
10. 改真实共享组件并逐项核验；服务端继续统一使用内置星河。按用户最后指示不做本地构建，核验后提交、推送并合并到远程主分支。源码合并与已安装版本更新分别核实。

## 消息与过程

- 普通对话、目标和循环共用原顺序：展开 goal 生命周期包装，在原位置依次展示思考、正文、工具、图片与后续内容。连续普通工具采用一致间距，复用现有过程归档入口。
- 工具调用数量不展示；不把后台启动回执当成后台任务完成。普通工具卡片不再携带可展开的参数、输出和错误正文。
- 思考标题为纯文字与小箭头，不加卡片背景、外框或内边距。当前思考流式时展开，结束后原位收起；手动选择优先。展开为灰字、左侧细线及内部滚动，最高桌面 200px、窄屏 160px，并受窗口高度约束，保留键盘和上翻阅读。
- 过程底部可收起。等待虚拟列表高度更新后恢复摘要焦点；如果用户已经移到其他控件，不抢回焦点。
- 连续工具执行中按过程密度展开，完成时按完成收起偏好原位收纳；手动打开旧段不会阻止新段继续收纳。失败不强制展开详情；原生权限提示继续可见。
- 展开工具过程后显示步骤名称、状态及可用来源详情；交互 HTML 作品、图片和最终结果正文保留真实结果入口，不附带原始工具回执。

## 追加消息

消息下的状态仅按同一消息 ID 对应的 `AgentInputItem` 显示：等待、提交、已送达、下一轮排队、失败和撤回。`consumed` 只表示送达，不表示已执行完成。
失去连接后，未完成送达显示等待恢复，控制入口禁用；内容保留。重新连接、回执和重试继续由原宿主管理，不新增前端确认计时器。
输入框上方保留一个紧凑待发入口，打开后使用原列表管理排序、重试、删除和安全强制发送；不再默认重复铺开所有宿主待发卡片。
复核时补齐发送回调对 `conn.agentInputs` 的依赖，避免使用旧待发数量决定新消息是否排队。

## 阅读与动画

沿用 `use-stick-to-bottom` 与虚拟列表。阅读旧内容时只标记新进展，不强行跳到新内容；自动出队不再递增“用户主动发送”的滚动信号。
新进展入口返回最新助手回复尾部，已经看见最新输出时撤回提示。提示是布尔状态，不把流式分片当作消息条数累加。
当前活动行、输出末尾与底部接替按可见位置切换工作动效。过程逐条动画、队列等待动画及重复的输入框运行环光被移除；保留原有多会话选中提示。
等待模型响应时，名称旁状态文字播放柔和流光；权限等待保持静态，完成后停止。页面隐藏、状态不在视口和系统减少动态效果时暂停。

后续截图反馈调整：当前状态与耗时移至原助理名称旁。按真实消息/活动快照推进阶段，取消 5 秒没有新分片即退回通用等待的判断；模型续轮等待显示最近工具名称。初始化与提交阶段不铺助手消息，进入模型等待后展示等待状态。
工具过程按小段收纳，不再先隐藏若干条后丢失对应展开入口。失败只显示状态，错误正文不在记录或悬浮标题中展示。
上下文压缩的“查看摘要”改用独立弹层，不受过程视口裁切。

## 后台、监听与消费

后台列表默认只给出目的、原生状态、查看和可用的停止操作。详细目的、运行时摘要、完整记录、子会话与精确消费按需查看。
活跃目标/循环在对话顶部共用一个精简任务条，优先显示目标，其余任务从计数菜单查看；结束和过期任务不占顶部。普通对话无活跃目标/循环时不显示任务条。目标标题可换行完整阅读；控制和补充要求复用运行时及原有草稿入口。循环只按原生快照显示调度已启用、执行周期和下次计划，不凭本机时钟模拟触发或归属。后台/监听仍经原任务菜单查看。
详情由会话展示上下文持有，入口隐藏、任务归档后不会误关；会话/连接域变化或标签页隐藏时不展示旧详情。任务从当前列表消失且状态不能确认时显示待同步，不伪造完成。
仅提供运行时协商出的原生操作；父回复结束不会停止后台或监听。循环取消仍需发送原生取消指令，子代理补充仍经主代理转达。
消费、账本扣点、请求去重、归属和精确小数继续使用原链路。追加要求、动画、监听等待不生成额外消费。
按用户最新要求，统计区只展示点数值，移除预估/确认前缀、来源说明和“已上报用量”。回复生成期间，点数随当前输入、正文和思考流式变化，并按模型目录价格本地估算；后端 Token 用量到达后只计算尚未上报的增量，已确认账单优先显示。估值不进入账本。缓存读取清除旧估值后按当前账号目录重算；价格或分类用量不足时隐藏点数。差异化推理/缓存 TTL 费率缺少明细时不猜测分摊。
正文字符数和调用数可以继续参与内部计算，但不在对话前端展示。首次响应、首字与用量各自更新，没有 Token 回执时不显示估算速度。

回复下方统计只展示有效数据，不显示“待统计”“未记录”“正文待输出”或工具调用次数；整行没有数据时不占位。首事件在前端流式批处理前按后端同一时钟的时间差记录，快照恢复保留已测得的相对时间，不能从历史内容补造首次时间。点数继续优先显示账本金额，缺失时使用既有模型报价估算；两者都没有时仅隐藏本行点数。
