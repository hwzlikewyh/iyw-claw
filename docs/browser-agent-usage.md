# Agent 浏览器调用

桌面版使用统一的内置浏览器工具。默认轻量 WebView；用户在设置中开启完整浏览器，
并安装、校验完整组件后，程序使用 Chromix。Agent 不选择、安装或启动另一套内核。
设置、切换和平台能力见 [双内核浏览器](browser-engines.md)。

## 调用链

内置 HTTP MCP 网关 → delegation listener → BrowserSessionManager → 当前活动内核。
旧 browser_* 兼容工具和 browser(action=...) 进入同一管理器。鉴权、回合租约、取消、
控制权、标签身份和人工接管沿用现有路径。用户界面显示 Agent 正在操作的原标签，
present 迁移原页面，不通过重新打开 URL 展示另一份页面。

流程：list_tabs → open → read/snapshot → click/fill/press/scroll/wait/advanced →
新 snapshot → 检查业务结果。

如果可靠的专用 API 或直接数据源已经覆盖请求，可以先使用该能力。用户明确要求
浏览器或任务需要页面交互时，使用网关返回的浏览器能力与实际 schema。

## 标签和引用

- 后续操作只回传工具返回的 browserTabId。
- 快照引用仅对应当时的页面；导航、SPA 路由变化、弹窗、DOM 更新或写操作后重新快照。
- stale/locator 失败对同一预期动作仅允许一次恢复：获取新快照并修正定位。
- 失败包含 effectMayHaveOccurred=true 时先读取状态，不自动重放写操作。
- 点击返回成功后仍检查 URL、文本、字段值、下载文件或其他明确业务信号。

## 展示与人工接管

present 展示当前原页面。request_user_action 只用于用户凭据、MFA/OTP、验证码、
设备批准、支付确认、确实无法自动完成的交互或明确的最终人工复核。普通定位失败、
页面慢或读取问题应先使用有界等待及一次快照恢复。接管完成后重新读取并验证结果。

用户、Agent 共用当前内核的持久登录数据。跨内核普通 Cookie 迁移不等于完整网站
状态迁移；缓存、IndexedDB 和 Service Worker 各自保存。Cookie、token、密码及
完整用户信息不得写入日志或报告。

## 高级操作

advanced 将 command 和逐项 arguments 送到当前内核，不经过 shell。完整内核
继续使用固定标签控制器；轻量内核使用 codeg 的隔离脚本和原生 API。基础导航、读取、
快照、点击、填写、按键、滚动、等待、截图、存储及 Cookie 操作共用入口。

各内核存在能力差异；不支持的选项返回错误，不能宣称执行成功，不能自动换内核重放。
现阶段轻量内核的跨 frame、网络追踪、上传、PDF、视口模拟、整页或引用标注截图、
局部快照和过滤读取尚未接入。完整内核保留原有高级能力。

应用管理标签、窗口、Profile、安装和配置。Agent 不能使用高级命令绕过这些管理入口。
内置浏览器关闭时，工具返回明确错误，不启动外部浏览器。

## 安装与诊断

轻量模式使用系统 WebView，不需要下载完整组件。完整内核由用户通过设置页安装或
修复，复用 Fusion 环境计划、摘要校验和原子激活。新安装默认跳过完整组件；已有
组件保留。安装完成不改写用户开关；活动页面、回合持有或下载会推迟内核切换。

OpenCLI 的外部页签、扩展连接和默认路由属于旧版流程，不再进入当前桌面浏览器
调用链。服务器模式不提供本机原生 WebView，设置项只在桌面显示。

按仓库规则不运行测试或在本机编译、启动桌面端。静态检查不能替代指定环境中的
登录、验证码、弹窗、下载、窗口迁移和内存验收。
