# 内置办公引擎

OfficeCLI-rust v0.1.31（固定提交7916bb354aaa9b25cb7c3d5270a6a2f441d84878）的文档处理库、命令解释器、帮助schema和办公技能全部编译进主程序。普通Word、Excel、PowerPoint和PDF的创建、读取、编辑、批处理不需要单独下载OfficeCLI。

## 命令入口

应用启动之前识别 `--embedded-office`，将后续参数交给内置解释器，随后退出，不启动桌面窗口、Web服务或业务初始化。保留 `officecli` 命令名，通过应用私有运行目录里的轻量脚本调用当前主程序。Agent环境和受管工具解析优先使用此入口，不依赖系统PATH上的旧OfficeCLI；不复制或下载另一个办公可执行文件。

技能同步直接读取内置资源。安装API仅修复入口并同步技能，不再运行网络安装器；界面显示“已内置”，停用只清理本应用拥有的技能链接，不删除主程序或用户自行安装的工具。应用升级一并升级文档引擎。旧环境计划中的独立OfficeCLI安装项会被跳过，旧组件不再作为运行环境缺失项修复。旧安装完成标记不用于判断内置技能是否已同步。

CLI命令层的上游没有公开Rust库，因此只将其命令层、schema和技能保存在 `src-tauri/vendor/officecli-embedded/` 并作入口适配；格式处理库继续使用固定git依赖。来源和改动清单在该目录README中，Apache-2.0许可随源码保留。此目录是第三方实现，既有大文件与长函数不按宿主新代码拆写。

## 预览

应用预览直接调用HCD导入库，在有界阻塞线程中生成不可变分片，不启动CLI进程。DOCX/PPTX沿用上游哈希与节点校验的懒加载视图；XLSX使用同版本HCD/Univer Canvas适配器按需读取，不走普通HTML的200行截断路径。前端资源随主程序内置，打开文件时不访问CDN。

每个文件共享一个可取消预览任务和回环HTTP监听器。现有文件引用、会话租约、能力令牌、代理与退出回收继续负责授权与生命周期。最后一个预览释放即取消，SSE关闭后监听器退出。解析任务在下一分片事件检查取消，结束前保留临时目录和导入槽位；最多两个并发导入。

活动文件每350ms采样，变化后再等稳定样本，复制源文件后导入；发布前核对源文件状态，避免显示混合版本。成功后SSE主动通知，保留当前与上一份分片；失败保留成功内容并显示错误。源文件上限256MiB。代理与本地入口均验证单文档能力令牌，不向预览传递宿主Bearer令牌。

## 保留的外部边界

内置常用办公处理不等于完整Microsoft Office。旧二进制格式的高保真转换可选LibreOffice，PDF转DOCX的特定路线可选Python转换器；显式截图或浏览器打印可使用系统浏览器。系统字体和特殊格式插件仍按各自依赖工作。默认DOCX/XLSX/PPTX操作及应用实时预览不要求这些可选工具。

Word物理分页、复杂PPT母版/动画、图片裁剪特效仍受上游能力限制，不承诺像素一致。人工编辑器未引入上游会退化DOCX表格样式的参考Tiptap投影。
