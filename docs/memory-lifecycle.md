# 记忆生命周期与云端语义检索

## 数据与权限

SQLite 权威快照保存事实、候选、修订、来源、有效期和撤回记录。Markdown 是可对账的兼容视图；FTS 和 Qdrant Edge 是可重建的派生索引。影子迁移先备份与校验，激活时校验 revision；外部修改走差异预览，旧备份不能绕过当前撤回代次。

召回在返回前重新验证来源版本、范围、敏感标记和有效期。纠正优先使用文档事务，旧内容退出当前召回；退役保留历史，明确截止时间由宿主过滤。彻底删除要求当前 revision 和 `FORGET`，清理权威记录、关联历史、全文和向量派生数据。仅保留不含正文的防复采哈希；Agent 追加、候选与后台提炼不能自动重新写入相同内容。删除备份是单独选项，未能清除的备份路径如实返回。该操作不承诺擦除磁盘空闲页或外部复制件。

主 Agent 的日常学习和维护沿现有宿主权限执行。模型复核建议不是事实：只有匹配当前来源、范围与明确纠正证据时才应用。过时建议自动关闭，已处置历史不会永久占满复核队列。

## 用户删除与清空

设置页单条删除使用二次确认，无需输入英文口令；服务调用仍提交 `FORGET` 与当前 catalog revision。旧版 Markdown 存储在用户确认后复用现有备份、影子导入和激活流程，再次校验原始 revision 后删除。

`POST /clear_user_memory` 与同名 Tauri 命令使用同一服务实现，请求包含 `scope`（`memory` / `all`）、`expectedRevision`、`purgeBackups` 和 `confirmation: "CLEAR"`。

- `memory` 清空记忆正文、候选、经验及自动生成画像，保留手写用户/灵魂内容及其停用状态。
- `all` 额外清空用户/灵魂正文；会话记录、应用配置和自动学习开关保留，后续新对话可以继续产生记忆。
- 清空不受分页、关键词、敏感内容隐藏或停用筛选影响。权威快照、记录历史、防复采哈希、召回关联和全文索引在同一事务内更新，向量索引沿现有锁顺序清理。
- 旧学习队列取消并移除文本引用；待入库提交保留无正文的去重记录，在途任务入库前重新检查清空标记。恢复日志同时记录清理范围，避免崩溃恢复只更新正文。
- 备份先扫描，再提交删除。备份清理与兼容文件导出失败分别返回残留位置，已提交的权威删除不会被误报为整体失败。全范围清空会检查全部已知服务生成的记忆备份。

清空结果返回 `clearedRecords`、`purgedBackupPaths`、`residualBackupPaths` 和 `residualFilePaths`。前端成功后刷新设置；版本冲突必须刷新状态并重新勾选确认。

## Agent 入口

记忆仅使用一个直接 MCP 工具 `manage_iyw_memory`，网关仍最多 12 个直接工具。内部 capability 不是新增直接工具。工具 schema 根据会话能力裁剪：禁用时隐藏记忆入口，只读时只列 policy/recall/documents.read。复核写入同时重新检查当前记忆写权限。

| 操作 | 用途 |
| --- | --- |
| `recall` / `documents.read` | 有范围的召回、最小原文读取 |
| `append` / `propose` | 明确长期信息、待验证观察 |
| `documents.correct` / `retire` | 原子纠正、停止当前使用或设置有效期 |
| `candidates.list` / `candidate.resolve` | 候选归纳与处置 |
| `maintenance.read` / `review.resolve` | 有界复核队列读取、应用或驳回建议 |

常用操作内联 schema；其余操作按工具公布的 capability 映射读取一次元信息。具体字段、并发冲突和失败恢复见随应用发布的 [Skill](../src-tauri/experts/skills/iyw-capability-gateway/SKILL.md)、[记忆策略](../src-tauri/experts/skills/iyw-capability-gateway/references/memory-and-learning.md)和 [10 个调用示例](../src-tauri/experts/skills/iyw-capability-gateway/references/memory-examples.md)。

## 模型与资源

- 后台提炼、画像归纳和旧记忆复核共用实时模型目录：已有配置仍在可用结构化模型列表中时优先使用，否则取该列表首项，顺序由 Fusion 目录控制。未配置用空模型值表示自动选择，运行时解析实际模型；设置页仅保存原配置与开关，不把自动选择固化为某个型号。目录为空时不发起提炼请求，仍可关闭功能。
- 结构化调用使用当前登录态的 `token` 请求头，并兼容 Bearer；HTTP 200 内的业务鉴权错误按鉴权失败处理。优先请求 `json_schema`，仅遇到明确的格式不支持错误时，在同一模型上改用 `json_object` 重试一次，将 schema 加入系统约束，并保留原有字段、来源与权限校验。输出截断、拒答与空正文分别报告，不能把推理内容作为记忆事实。
- 画像生成提示词限定最多 6 段、每段少于 120 字符、最多 2 个有效来源，匹配现有 2500 token 输出预算；不提高预算、不追加截断重试，既有画像存储上限保持兼容。发送画像请求前复用前台活动门控，只有后台任务等待；发送和首字路径不增加网络调用或等待。后台提取遇到 502 仍走现有持久化重试队列，不触发主对话重试。
- 保留 Qdrant Edge 0.8.0 本地向量库；嵌入和重排经 Fusion 转发，客户端不保存厂商密钥，也不下载、加载或打包嵌入模型。
- 语义召回默认启用；模型由 Fusion 按能力、可用权限和目录排序决定。客户端使用各类目录的首项，按账号身份缓存 60 秒，过期后在下一次检索或显式准备请求中刷新。嵌入或重排目录为空时分别停用对应增强，保留全文检索。
- 设置页只保留自然语言搜索框、搜索结果和必要的错误反馈，不展示语义开关、模型选择、下载或索引刷新。搜索预览复用 Agent 召回路径，不追加云端状态请求；召回不可用时显示错误，云端增强失败时保留已有全文结果。启动、定时维护和记忆写入只更新本地数据与全文索引，不触发云端向量索引刷新。旧本地选择及语义开关不再读取，旧写接口明确拒绝覆盖检索策略。整体记忆关闭仍停止云端检索；不删除用户已有模型文件或记忆。
- 向量索引在实际检索时按需恢复并补齐；先读取磁盘已有向量 ID，再嵌入缺失内容。补齐与查询共用本次检索时限，失败或超时保留全文结果和已经写入的向量，等下一次需求继续；没有后台定时重试。兼容的显式准备接口只执行一次，最多等待 3 秒。
- 建连不等待记忆索引重建，未就绪时复用既有后台刷新。每轮自动注入仅尝试本地召回，总预算 50 ms，包含读取、来源版本校验和上下文准备；冷索引或来源变化时跳过本轮预取，不在发送前同步修复索引或调用云端嵌入、重排。需要更多证据时由 Agent 显式调用召回或文档读取；预取未命中不代表不存在相关记忆。
- 向量搜索使用 1 个线程，索引构建和查询计算分别限制为单任务。显式检索保留现有冷索引准备、3 秒语义查询及 700 ms 可选重排预算，失败保留已有本地召回结果。
- 记忆按 UTF-8 字节预算分块，索引按 Fusion 身份、模型、分块版本和实际维度隔离。只向模型发送有效、非敏感文本；命中仍须回到本地权威记录检查版本、作用域与有效期。
- 5 分钟未使用后由维护周期释放索引及查询缓存，释放不会重新触发模型调用；下次检索按需加载。索引加载失败在 writer lock 下清理派生数据并从当前事实重建。
- 桌面派生索引位于用户记忆目录；server 构建使用配置的数据目录。不能把多个用户或多个独立进程当作同一全局记忆实例。

## 2026-09-21 历史验证记录

以下为云端迁移和 Fusion 接管策略前的历史结果；其中模型下载、冷加载及默认关闭描述不代表当前实现，本次变更按静态审查交付。

按仓库约定未运行测试套件；使用生产服务的隔离合成数据验收、真实 MCP Streamable HTTP 调用、静态检查和构建。

- 前端完整构建导出 35 页；相关 TypeScript/TSX 的 ESLint 通过；10 个 Skill JSON 示例逐个符合实际 capability schema，链接有效。
- 桌面与 server 代码检查、隔离验收程序编译通过。桌面代码检查使用不含打包资源的临时环境覆盖，不等于安装包构建成功。
- 迁移幂等、精确纠正、旧 etag 拒绝、重复观察去重、否定分离、过时复核关闭、到期后重新追加不复活均通过。
- MCP 禁用/只读/可写分别返回 11/12/12 个工具；只读写入被拒，当前写权限关闭后复核处置被拒，重新启用后按新 revision 成功处置。
- 语义关闭时下载成功且未加载推理；同大小模型内容损坏后自动恢复，恢复期间 FTS 可用；向量配置损坏后重建，保留权威事实。
- 使用不可达 Fusion 地址制造下载失败后，重试状态和截止时间持久化；重启到真实 Fusion 后由后台 worker 自动恢复，无需再次点击准备。
- 彻底删除后即使语义关闭，向量目录也只剩 writer lock；Agent 再追加同样内容被防复采约束拒绝。
- 1440 和 390 宽度的记忆设置页无横向溢出、无页面脚本错误、记忆接口无失败响应。隔离界面未模拟完整宿主健康状态。

小样本 Windows debug 隔离进程含 HTTP/MCP/SQLite：加载后工作集约 178 MiB，空闲释放后约 78 MiB，私有内存约 126 MiB 降至 25 MiB；空闲观察期 CPU 累计时间基本不变。首次 Fusion 下载约 20 秒，冷恢复预览约 7 秒，不能等同热查询延迟。这些不是整个桌面应用的内存增量，也不是 100k 或跨平台性能结论。

新增的 12 条合成查询在第一次运行前固定，没有按结果调阈值：FTS 与混合均为 5/12，其中 10 条检索为 3/10、2 条常识负例均正确弃权。这组没有证明向量净收益，不能用旧 10 条固定回归的较高成绩替代它；语义配置继续默认关闭。热查询本次 FTS 为 23-151 ms，混合为 51-73 ms，小样本范围不代表规模性能。

固定或合成案例不能证明长期真实任务成功率。时间拆分的真实会话保留集、规模压测和上线采用反馈需分别留证，不能把召回或注入次数当作实际改善。
