# 星河内核 0.166.0 升级记录

日期：2026-11-04。

## 目标与验收

内置星河从 0.165.0 升至官方稳定版 0.166.0，沿用进程内运行时与现有 ACP
桥接。更新范围为应用源码和固定依赖；已安装应用需要后续构建发布才会更新。

1. 官方标签对象、源码提交、生产依赖和内置运行时身份保持一致。
2. 保留宿主认证与环境、进程内 MCP、命令描述、图片、任务消费归属、压缩预算
   及 Windows/Win7 兼容补丁。
3. 依赖解析、生产模块与资源、协议导出、迁移 SQL、Rust 语法和差异检查通过。
4. 保留工作区已有账户余额修改，遵循仓库不运行测试及不在本机编译桌面端的规定。

## 迁移决策

以 0.165.0 官方源码、本地覆盖源码和 0.166.0 官方源码三方比对，迁移 22 个生产
覆盖包。保留宿主凭证与环境、进程内 MCP、已发布 MCP 状态、命令描述、托管图片、
压缩预算、任务消费归属和 Windows/Win7 兼容补丁。

新版线程条目采用扁平 payload 加可选生命周期时间戳，命令描述及压缩摘要扩展继续
写入 payload 和预计算协议资源。终端输出改为 `CapturedStream`，直接命令和
`write_stdin` 图片捕获读取其文本字节；轮询缓冲区引用上游新工具包。启动任务保留
宿主的取消即中止保护，同时采用上游新的线程监听与关闭流程。0.166.0 的核心
异步依赖图需要 `recursion_limit = 256`，该设置仅改变编译查询深度。

原生状态迁移 SQL 与官方 78 个文件一致；本次没有打开用户数据库或执行迁移。
源码更新不修改应用发布版本、已安装程序或 Fusion 的受管分发策略。
