# 工具发现优化（2026-10-29）

## 目标与边界

在现有宿主能力目录和远程业务目录上改善召回与候选呈现，不新增依赖、接口字段、模型请求或账号权限。不改变 source 选择、每来源 limit、分页游标、工具版本校验和执行授权。

## 实现

- 本地 capability_metadata::search_score 在判定无匹配前计算 intent_terms；中文长句即使没有空格，也能凭已有意图词进入候选。原有精确 ID、别名、短语与排序权重保持不变。
- remote_mcp::directory 合并结果时优先精确 ID、名称或别名匹配，其余按各来源排名交错，避免远端首项被整段本地结果压后。
- 相同 capability_id 只返回一次，保留排序更靠前的定义；不以名称去重，避免合并不同账号或版本的能力。
- source=local 仍直接返回本地结果，不等待远程。source=remote 和 browse 仍只保留该来源，每来源顺序在没有精确匹配提升时保持不变。source=all 仍最多返回各来源 limit 条，而非把旧接口改成总 limit。

## 取舍

采用已有元数据与排名做轻量改进。跨来源全量模型重排会增加延迟和外部依赖；自动决定 source 会影响明确指定的范围，本轮均不引入。交错呈现不等同于经过统一模型校准的全局相关性排序。

## 验证

遵守本项目 AGENTS.md：本轮不新增或运行单元/集成/端到端测试，采用静态调用链审查与编译检查。中文长句召回检查重点为“帮我创建一个每天上午九点执行的定时任务”和“帮我记住我更喜欢使用简体中文回复”；核对意图词参与门槛及原有精确排序权重。

合并审查覆盖空来源、精确别名、重复 ID、同名不同 ID、远端失败、source=local/remote、browse 分页及目录版本传递。远端失败继续保留本地结果并返回 unavailable 提示。

远端网关对应修改记录见 iyw-mcp-gateway/docs/generic-capability-mcp/cloud-tool-discovery.md 的 2026-10-29 小节。当前工作区修改不表示已部署或已完成真实模型效果评测。
