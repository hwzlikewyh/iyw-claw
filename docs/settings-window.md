# 设置窗口

桌面端通过 `openSettingsWindow` 调用宿主 `open_settings_window`，直接加载已有
`/settings/<section>` 静态页面。Web 工作区继续使用设置 dialog。

- 本地设置窗口固定使用 `settings` 标签，远程工作区使用 `remote-settings-<id>`，
  分别复用窗口。后端串行处理打开请求，避免快速重复点击创建多个实例。
- 重复打开会恢复并聚焦已有窗口，按请求切换设置项，保留远程连接和窗口实例 ID。
- 设置独立页面提供账户、更新和侧边栏显示选项的上下文，不依赖工作区组件树。
- 桌面工作区不加载设置 dialog 组件；设置内容在独立 WebView 中加载。
- 本地托盘打开设置时先恢复主窗口；标题栏关闭和“返回工作区”均关闭设置窗口。
  真正销毁后移除归属记录并聚焦来源窗口，复用现有远程实例销毁钩子清理订阅。

验收重点：首次打开、重复打开、最小化后再打开、指定 Agent 设置项、本地和远程
上下文隔离、标题栏关闭、“返回工作区”关闭，以及关闭后再次打开。
