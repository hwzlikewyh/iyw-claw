# Windows 升级安装目录

Windows 默认升级沿用产品独立注册表项
`HKCU\Software\iywclaw\iyw-claw` 中的 `InstallRoot`。
发布者名称改变时，安装位置不再依赖 Tauri 的发布者注册表项。
这能避免升级误装到 LocalAppData 后创建新库，使旧历史看起来消失。

## 目录选择

- 显式 `/D=` 优先；完整路径使用 NSIS 已解析的 `$INSTDIR`。
- 未指定目录时优先恢复已保存的逻辑根目录；旧的 `root\app` 记录先归一化。
- 无有效旧记录时，首次安装使用 `$LOCALAPPDATA\iyw-claw`。
- 交互目录页后续选择保持有效；静默安装也执行同样的默认目录恢复。
- 权限恢复入口继续采用已校验的原用户目录。
- smoke 安装使用独立注册表和绑定临时根目录，不读取生产卸载项。

应用默认从逻辑根的 `data` 读取数据库，从原有 agent 存储设置解析 profile。
本修复不迁移、合并或覆盖数据库。

## 更新参数

已安装应用发起更新时，复用 `desktop_bootstrap::resolve_install_root`，
从 `root\app\iyw-claw.exe` 得到 `root`，通过 updater 的 `installer_arg`
追加 `/D=root`。开发目录不符合已安装布局时，保留现有行为。

NSIS 要求 `/D=` 位于参数末尾且不加引号，即使目录包含空格。
该参数会从 `$CMDLINE` 中移除；安装器通过 Windows 原始命令行检测是否指定了
`/D=`，不自行重新解析完整路径。安装器内部再次启动时同样传递所选目录。

旧版应用未携带 `/D=` 时，含修复的新安装器仍可通过产品独立记录恢复原目录。
只有使用包含此修复的源码打包后，相关行为才会对用户生效。

## 验证范围

审查默认升级、发布者变化、旧版更新入口、首次安装、显式目录、目录页修改、
静默安装、权限恢复及 smoke 隔离的调用链。编译检查不等同于实际升级回归；
正式发布前还需在隔离安装环境核对历史列表和会话内容。
