# 聊天渠道专属工具

从微信、企业微信、飞书或钉钉发起的任务，会在 Agent 真正接受回合时绑定到当前账号、会话和目标。专属工具只开放这个任务的当前渠道能力，工具参数不能选择其他账号或收件人；既有全局渠道管理工具继续遵循原有权限。

## 长任务进度

默认每 120 秒发送一次客观状态摘要。任务文本中写“每五分钟汇报一次”会使用指定周期，允许范围为 30 秒到 24 小时。运行期间可以直接发送：

```text
查看进度
改成每五分钟汇报
停止汇报，继续执行
只告诉我重要进展
恢复汇报
取消任务
```

有多个并行任务时，消息会返回任务编号前缀，使用 `进度 #编号`、`停止汇报 #编号` 或 `取消任务 #编号` 选择任务。停止汇报只关闭普通周期通知，任务和最终结果仍继续交付。取消会核对所属回合；旧任务与新任务复用同一连接时拒绝取消旧回合，避免停止新任务。

状态来自运行会话、工具调用、待回答问题、权限确认和已登记的后台委派。无法确认时会报告“状态未知”，不会生成完成百分比或预计完成时间。重要里程碑、等待用户确认、断线和最终状态会走优先通知路径。

## 当前渠道工具

Agent 可通过现有 MCP 网关搜索 `current channel` 或 `当前渠道`，然后读取本次返回的精确 capability ID。工具包括：

- 查看当前渠道上下文和任务进度
- 修改本任务汇报周期或记录公开里程碑
- 向当前会话发送文字、图片和文件
- 发送带操作的任务卡片

企业微信智能机器人额外提供受宿主管理的流式回复和企业微信业务 CLI。业务调用必须先用 `help` 或 `schema` 获取当前版本的精确参数；文档、智能表格、日程等命令受账号权限限制。账号凭据按机器人和 secret 指纹隔离，账号上下文变化会拒绝执行。

企业微信和飞书使用原生交互卡片；微信、钉钉等当前没有统一验证的按钮能力时，交互会降级为带 `操作 <id>` 的文字指令。所有按钮和文字操作都绑定发送者、会话目标、任务编号和 10 分钟有效期。

## 运行边界

微信 iLink 的上下文 token 过期时暂停普通进度，记录投递原因；已经由后端接受的排队消息沿用原有发送队列。发送结果未知时不盲目重放同一终态。企业微信流式消息由宿主管理 stream ID，至少间隔 1 秒刷新，并在回合结束或 9 分钟时尝试发送结束帧；超过平台窗口后不再续写。

当前任务跟踪保存在进程内。应用重启后不承诺自动恢复周期订阅；恢复会话需要用户再次发消息，系统会重新校验渠道和目标。每次进度投递都会写入渠道消息日志，区分已发送、排队、失败和结果未知。

本次未进行真实渠道账号联调；卡片显示、平台权限和推送送达仍须在对应账号验证。
