# 聊天渠道专属工具

从微信、企业微信、飞书或钉钉发起的任务，会在 Agent 真正接受回合时绑定到当前账号、会话和目标。专属工具只开放这个任务的当前渠道能力，工具参数不能选择其他账号或收件人；既有全局渠道管理工具继续遵循原有权限。

## 长任务进度

默认不发送周期文字状态。执行期间使用渠道支持的“正在输入”；产生新的阶段成果、需要回答或确认、发生异常以及最终完成时才发送消息。相同阶段说明不会重复触发通知，短时间内的阶段成果沿用合并窗口。

任务文本中明确写“每五分钟汇报一次”会开启指定周期，允许范围为 30 秒到 24 小时。运行期间可以直接发送：

```text
查看进度
改成每五分钟汇报
停止汇报，继续执行
只告诉我重要进展
恢复汇报
取消任务
```

有多个并行任务时，消息会返回任务编号前缀，使用 `进度 #编号`、`停止汇报 #编号` 或 `取消任务 #编号` 选择任务。停止汇报只关闭普通周期通知，任务、连接维护和最终结果仍继续交付。“恢复汇报”开启当前周期；没有指定过周期时使用 120 秒。取消会核对所属回合；旧任务与新任务复用同一连接时拒绝取消旧回合，避免停止新任务。

状态来自运行会话、工具调用、待回答问题、权限确认和已登记的后台委派。无法确认时会报告“状态未知”，不会生成完成百分比或预计完成时间。重要里程碑、等待用户确认、断线和最终状态会走优先通知路径。

## 当前渠道工具

Agent 可通过现有 MCP 网关搜索 `current channel` 或 `当前渠道`，然后读取本次返回的精确 capability ID。工具包括：

- 查看当前渠道上下文和任务进度
- 修改本任务汇报周期或记录公开里程碑
- 向当前会话发送文字、图片和文件
- 发送带操作的任务卡片

企业微信智能机器人额外提供受宿主管理的流式回复和企业微信业务 CLI。业务调用必须先用 `help` 或 `schema` 获取当前版本的精确参数；文档、智能表格、日程等命令受账号权限限制。账号凭据按机器人和 secret 指纹隔离，账号上下文变化会拒绝执行。

企业微信和飞书使用原生交互卡片；微信、钉钉等当前没有统一验证的按钮能力时，交互会降级为带 `操作 <id>` 的文字指令。所有按钮和文字操作都绑定发送者、会话目标、任务编号和 10 分钟有效期。

## 运行边界

用户不继续发消息时，连接保活与任务跟踪继续运行。微信沿用长轮询和原生 typing；飞书使用服务端指定间隔的业务心跳；企微智能机器人和钉钉沿用协议心跳与自动重连；自建应用和旧企微 CLI 按各自凭据刷新机制发送。后台任务未结束时，微信 typing 会继续；等待用户回答时暂停，整体任务结束后停止。

微信 iLink 的公开接口没有可验证的上下文静默续租保证。typing 成功不代表正文必能发送，含义不明确的 `-2` 不再一律清空 token。上下文不可用或被拒时保留交付，等待同一账号、同一接收人的新有效上下文。账号会话错误、限频与明确的上下文过期分别处理。

企业微信普通正文通过主动发送接口交付，流式展示使用独立接口。宿主管理 stream ID，至少间隔 1 秒刷新，并在回合结束或 9 分钟时尝试发送结束帧，预留平台总时限；流式结束不会停止后台任务。钉钉在 session webhook 过期或明确拒绝时切换到单聊/群聊 OpenAPI，未知网络结果不会触发第二次主动发送。

文字和附件复用现有 outbox 表保存交付状态，附件暂存副本总量上限 512 MiB。发送前重新核对原账号身份和原目标；同一目标按顺序交付。暂不可连接、需要重新获取凭据或限频的交付退避重试；等待微信新上下文的交付只在上下文变化后重试。尚未发送的同任务进度会合并，任务结束后旧进度不补发。成功后清理对应附件副本。账号或目标被改变、明确拒绝以及结果未知的项目保留记录，不能把这些状态当作送达成功。

当前任务跟踪保存在进程内。应用重启后不承诺任务持续执行或自动恢复周期订阅；已登记但明确尚未发送的文字和附件会恢复交付。发送中退出或响应未知的项目不自动重放，以免重复发送。休眠或断网期间无法发送心跳，恢复后由连接重连与待投递流程处理。每次进度与恢复交付写入渠道消息日志，区分已发送、排队、失败和结果未知；平台受理不等于客户端已读。
