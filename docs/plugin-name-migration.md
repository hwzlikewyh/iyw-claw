# 官方插件名称兼容迁移

这次迁移为 27 个已有官方插件去除名称中的旧宿主前缀，市场 ID、作者归属与版本历史保持同一条目。七个 Craft 插件同时修复 Blob 模块和 WASM 的 CSP 声明。

迁移表位于 `src-tauri/src/models/plugin_names_data.rs`，与 Fusion 的 `internal/domain/skill/plugin_renames_data.go` 按 ID 一致。它只处理这些已存在的条目，不接受来自任意包的迁移指令。

已有安装使用可信 `current.json` 中的市场 ID 识别旧、新名称。升级复用原安装目录和账号隔离的数据目录；当前安装记录、组件与运行时采用新名称。这样无需搬动作品或改写历史包摘要。新安装直接使用新名称目录。两种目录同时存在、目录为链接或指针归属不符时，保留原数据并要求先恢复安装。

配置和凭据本来就按账号、市场 ID、工作区和连接器保存。授权及启用状态在原安装事务中从旧名称继承到新名称；恢复旧快照时也清理失败版本的状态。插件技能按相同 ID 和组件继承运行环境及发布开关。历史收据保留原包名称，回退、恢复和卸载通过相同目录规则完成。

Fusion 按迁移版本边界返回历史名称，旧依赖仍按固定别名解析至原 ID。改名与新版本指针在现有逐文件上传完成事务内提交，失败不改变名称；旧、新名称均保留给原官方条目。

## 发布顺序

1. 发布包含迁移代码的客户端 0.1.363，以及对应 Fusion 兼容实现。
2. 27 个候选包沿原市场 ID 上传，清单名称和能力 ID 使用新名称，`minClientVersion` 至少 0.1.363。服务器拒绝将改名版本发给不兼容宿主。
3. 完成上传后回读名称、版本、摘要与 ZIP 状态；将既有插件统一设为公开市场、活动状态。
4. 核对旧版本恢复计划仍与原名称/摘要一致，当前用户可以取得新包安装计划。

0.1.363 是本次兼容版本的计划发布号；正式上传以该版本确已发布、且源码包含本次迁移为前提。未通过发布门禁时保留候选，不提前提交改名版本。

本地验证包括 Rust 共享库编译和调用链审查；遵循本仓库约定，不新增或运行测试套件。七个编辑器的真实作者预览已确认模块、WASM、画布和自动化桥全部就绪。正式安装与各平台升级验证由发布流程及上线回读继续核对。
