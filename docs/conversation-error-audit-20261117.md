## 实施

- 兼容直接和旧流包装的标准输出预算错误，按完整 reason token 判定，拒绝相似前缀和其他 reason。
- 阻止压缩或过时代际错误触发用户续写；沿用既有 had_output、活跃工具和授权等待条件。
- 内核重试识别新增 ResponseIncomplete(max_output_tokens) 类型，使同一请求重试与宿主续写分工一致。
- 其他日志错误分类、证据行和修复状态保存在本机审计报告；不改用户的安全拒绝或浏览器网络策略。
