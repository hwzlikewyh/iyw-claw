# 图片任务队列栈溢出修复

Windows 安装版 0.1.287 于 2026-10-19 18:39:11 发生
`0xC00000FD` 线程栈溢出。崩溃前图片工具已选定 Fusion 模型，
尚未完成图片输入准备。

原生转储显示，工作线程已使用约 7.59 MiB 栈，随后迭代器再次
申请约 2.24 MiB 栈；相邻栈帧占用约 4.48 MiB。图片准备队列直接
保存大型 Future，迭代时按值移动完整异步状态，存在相同的栈放大路径。

输入图片准备、Fusion 输出物化与上传、裂变任务轮询三处队列改为
保存 `Pin<Box<Future>>`。Windows x64 上队列元素为一个指针，
迭代不再搬运完整 Future。并发上限、结果顺序、超时、取消和
错误汇总沿原链路执行；线程栈容量保持现有设置。
