# 账号登录与企业空间

账号功能沿用 `IywAccountProvider`、Tauri/Web transport 和 Rust 账号核心。界面跟随应用当前主题，顶部空间切换在 `FolderTitleBar` 右侧工具区；账号菜单保留资料、点数、设置、使用统计、连接器、个人记忆、外观、会话管理器、更新和注销。

## 登录流程

- 微信扫码、密码与短信登录共用 `iyw_account_auth`，Web 请求同样使用 POST。
- 微信轮询只返回 `wechatKey` 时，必须验证并绑定手机号，再处理身份及空间引导；没有跳过绑定入口。
- 手机号验证码登录支持上游自动注册；设置密码注册和手机号找回密码使用独立表单。改密成功返回密码登录，不直接开放工作区。
- 未完成身份、无可用空间或需选择主体时，后端返回非敏感流程 ID；微信 key、`sessionKey` 和正式 token 留在 host。
- 短信原始票据同样留在 Rust。UI 的 `captcha_key` 是本地票据 ID，host 校验手机号和业务场景，再转换成上游票据。
- 当前不实现原生滑块。服务端要求安全验证时显示官方账号中心入口；微信待绑定仍保持未登录，完成官方绑定后重新扫码。

登录完成必须有合法正式 token、用户 ID 和当前空间。验证码错误、待绑定、待主体选择或 HTTP 200 中的业务失败，均不能被当成登录成功。二维码刷新和取消有版本检查，旧轮询结果不能提交新会话。

## 企业空间切换

1. 使用服务端当前账号的 `orgList` 校验目标成员权限，停用空间不可切换。
2. 拦住新的消费请求，确认没有正在运行或等待完成的 Agent 回合；随后请求 `switchWorkspace`。
3. 清理旧空间派生数据和业务凭证，再请求 `login/product`。
4. 重新读取 `getMyInfo`，确认目标 `orgCode` 后更新 UI。保留本地文件、项目和会话。

明确业务拒绝时恢复原空间。超时先读取实际主体，避免盲目重发切换写操作。确认失败时保持 `workspace_pending`，新请求暂停；空间菜单可以重新同步。主体已切换而供应链凭证未刷新时，仅提示对应服务待恢复，不能宣称回滚或清主账号会话。

供应链工具调用 `scm-demo.iyw.cn` 使用 host 保存的专用 token 与 `iywCode`。其他爱原物工具继续使用主 token。凭证不同步时明确拒绝供应链请求，不冒用旧企业凭证。

## 点数暂时查不到

同一账号/空间的最后合法余额与失败计数保存在既有账号 metadata 中，无数据库 schema 变更。

| 查询结果 | 行为 |
| --- | --- |
| 有效余额，包括真实 0 | 更新余额、清零失败计数，解除查询失败造成的限制 |
| 连续失败 1–9 次 | 保留原余额，标识尚未更新，继续使用 |
| 连续失败达到 10 次 | 保留余额与登录，暂停消费新请求，允许刷新和本地操作 |
| 限制后查询成功 | 自动恢复 |

同一次并发资料请求复用结果，不按渲染次数计数；实际已完成的点数查询失败才累加。没有历史成功余额时不伪造数字。换账号/空间时不沿用旧余额，服务端实际消费准入仍是最终依据。

界面发送入口、Agent 输入、共享 prompt 调度与 Fusion 生成路径都检查准入；已经执行的回合不会因为查询失败被强行取消。真实用户资料鉴权失败仍要求重新登录，点数服务失败不等于账号失效。

## 会话与验证

记录绝对到期时间，认证凭证读取在剩余 30 分钟阈值内续期，返回秒数换算为毫秒时间戳；不替换未返回的新 token。并发复用续期，旧会话结果不能恢复已注销账号或覆盖新空间。旧安装的无绝对时间会话首次读取时按服务端续期确认。

按项目 AGENTS.md 不新增或执行自动化测试，使用 TypeScript、定向 lint、Next 构建、桌面/服务器 Cargo 编译及静态调用链检查。源码组件效果图使用演示账号，未在真实账号上执行短信、注册、手机号绑定或企业切换；这些流程仍需专用账号端到端验收。
