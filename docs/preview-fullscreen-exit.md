# 预览全屏退出（2026-10-20）

用户反馈案例视频放大后无法返回。音视频、Markdown、Office、3D 模型的
调用方仅请求进入浏览器全屏，共用工具栏没有识别原生状态或执行退出。

## 共享修复

`PreviewToolbar` 通过 `useNativePreviewFullscreen` 识别全屏元素是否包含
当前按钮，监听 `fullscreenchange` 更新图标、文案和无障碍状态。
再次点击时根据浏览器实际状态退出；尚未进入原生全屏时执行原有回调。
Esc 在当前预览拥有原生全屏时优先退出，并阻止父级弹窗处理同一次按键。
禁用时不注册监听，卸载时清理；退出失败记录错误。

修复沿用当前 DOM 和各预览资源生命周期，不重新挂载媒体、文档或 Office 会话。
PDF 继续使用受控 `PreviewFullscreen`；成果预览继续隐藏子工具栏的重复全屏按钮。

## HTML、网页与其他入口排查

| 入口 | 放大后的返回路径 |
|---|---|
| 工作区 HTML | 文件栏同一按钮按 `filesMaximized` 显示最大化或还原 |
| HTML/URL 成果 | 外层 `TaskArtifactPreview` 标题栏的缩小按钮；资源弹窗另有关闭入口 |
| 交互 HTML / 原生网页面板 | 面板顶栏关闭按钮只修改本地打开状态，返回不依赖表单提交 |
| 插件 HTML | 父组件控制放大/缩小，退出按钮位于 iframe 外 |
| 智能 UI | 受控 Radix Dialog 保留关闭按钮 |
| 图片 | 图片查看器关闭按钮与 Dialog 打开状态 |
| CSV、普通文本、二进制 | 沿用成果预览父级的放大及返回入口 |

这些入口未发现同类单向原生全屏调用，未额外增加全屏入口或修改沙箱权限。
iframe 内键盘事件不冒泡到宿主：上述外层按钮可独立控制返回，宿主的 Esc
监听不能视为 iframe 聚焦后的 Esc 支持，本次未新增跨文档消息桥接。

## 验证范围

交付检查包括定向 ESLint、TypeScript 无增量检查、diff 检查，以及沿原生
全屏事件、按钮回调、嵌套弹窗和卸载清理路径的静态审查。
遵循客户端仓库规则，未新增或运行自动化测试；未做真实浏览器和 Tauri
桌面交互验收，iframe 焦点、原生播放器及系统快捷键仍需实机核对。
