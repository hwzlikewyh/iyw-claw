# 会话标签与独立窗口

在「设置 → 通用 → 会话标签」中设置每个窗口的最大标签数。默认值为 8，
设为 0 表示不限制。设置保存在本机界面偏好中，对已打开的窗口即时生效。
调低上限会保留已有标签；达到上限后，需要先关闭标签或提高上限再打开其他会话。
重复打开同一会话会激活已有标签，不占用新的名额。

普通单击侧栏会话会保留标签。标签保持单行，超出宽度后可横向滚动，
切换时自动显示当前标签；原有排序、分屏和快捷键继续有效。

桌面应用中，将会话标签向下拖离标签栏并释放，即可拆成新的独立窗口；
拖到整个窗口外再释放也同样有效。窗口内的标签排序和跨分屏移动继续生效。
也可以右键标签，选择「移动到新窗口」。

独立窗口只显示这段对话和输入框，顶部保留会话标题与窗口控制按钮，
没有左侧会话列表、工作区导航、右侧文件栏或终端。拖动顶部空白处可移动窗口。

将独立窗口顶部的会话标题拖回原窗口的标签栏，即可合回原标签页；
也可以点击「还原到主窗口」。接收方准备完成后才关闭独立窗口。
原窗口已有的其他标签、草稿和运行任务均保留。原窗口已关闭、存在重复会话
或标签数量已满时，会保留独立窗口并提示原因。

目标窗口准备完成后，来源窗口才移除标签。交接保留会话身份、工作目录、
模型和模式、运行状态、输入草稿及已经准备好的附件，不重新启动正在工作的 Agent。
交接失败或超时会保留来源标签。连接初始化、附件处理中、存在失败附件或正在编辑
队列消息时，请先完成相应操作，再移动会话。

关闭独立窗口不会删除会话记录；连接继续遵循既有的活动保护和空闲回收规则。
服务器的浏览器界面保留标签设置，不提供桌面窗口拖出功能。

系统分享的自动接收由主窗口负责，避免多个本地窗口重复打开同一份分享草稿。
拆出的窗口保持纯对话界面。

## 实现与验证

前端沿用 TabStore、会话运行状态和连接快照机制；独立窗口复用 `/workspace`，
通过一次性交接标识传递状态，输入内容不写入 URL 或日志。后端负责创建窗口、
校验来源和接收方、转移本地连接归属，以及回退和关闭清理。

验收重点为：默认上限、0 不限制、跨窗口设置同步、重复打开、调低上限、
窗口内排序和分屏移动、历史会话和草稿拖出、运行中拖出、附件和引用恢复、
纯对话布局、窗口移动、拖回和按钮还原、还原失败回退及关闭独立窗口后的任务保护。

Rust 编译检查的结果记录在本次交付说明中，实际桌面拖拽仍需进行人工验收。
