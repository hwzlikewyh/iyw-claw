# 插件参数与业务账号准备

v2 HostGateway插件可以在每个connector上声明可选`preparation`。它随原`.iyw-plugin.json`上传、校验、计算摘要和发布；已发布版本修改时仍须上传新版本。旧清单不声明此字段时保持原摘要和准备行为。v1插件继续通过连接器管理配置。

## 发布者声明

```json
{
  "key": "documents",
  "transport": "stdio",
  "runtimeKey": "documents-node",
  "routing": {"mode": "host_gateway"},
  "activation": {"mode": "lazy", "scope": "workspace"},
  "preparation": {
    "parameters": [
      {"key": "SERVICE_ENDPOINT", "label": "服务地址", "required": true},
      {"key": "SERVICE_TOKEN", "label": "访问密钥", "required": true, "secret": true}
    ],
    "authentication": {
      "status": {"toolName": "account_status", "arguments": {}},
      "authenticatedPointer": "/structuredContent/authenticated",
      "login": {"toolName": "begin_login", "arguments": {}},
      "authorizationUrlPointer": "/structuredContent/authorizationUrl",
      "logout": {"toolName": "disconnect_account", "arguments": {}}
    }
  }
}
```

工具名和环境变量仅为结构示例，发布者须依据插件真实实现填写。status/login/logout须是同一connector在capabilities中声明的不同工具。status对应能力的`readOnlyHint`须为true，运行时实际`tools/list`返回的工具注解也须明确只读，才允许调用。MCP方法和字段依据本项目锁定的rmcp 1.3.0源码；不猜测供应商工具或参数。

`authenticatedPointer`作用于完整MCP CallToolResult的JSON序列化值，必须取得布尔值；不将任意成功字符串、空结果、进程退出或初始化成功当作已登录。上例要求`structuredContent.authenticated`为true/false。登录地址同样使用明确JSON Pointer，客户端仅打开HTTPS或本机HTTP地址，拒绝嵌入用户名/密码。未声明login或logout时不提供对应操作；可以只声明status，登录仍由插件自身界面完成。

parameters最多32项，环境变量名称唯一；参数值是字符串。支持label、description、required、secret、defaultValue和placeholder。密钥必须secret且不能有默认值；宿主凭据前缀、HOME/APPDATA/XDG/PATH、动态加载注入变量及专用*_DATA_DIR等保留名称不可声明。认证工具的arguments必须是明确对象，不能携带密钥或模板；密钥从安全保存的参数经环境传入。

作者可运行：

```sh
node src-tauri/experts/skills/plugin-creator/scripts/validate_plugin_preparation.mjs <plugin-directory>
```

该命令只校验准备声明。完整包仍由原发布器和服务端验证，命令不会登录、调用业务工具或证明运行时可用。原生导入器也复用该校验，不自动推断登录工具。

## 后台配置

Fusion正式后台的插件创建、新版本和恢复上传表单有“连接器参数与账号准备”编辑器。按connector key填写准备对象，选择文件夹时读取原声明；留空保留、`{}`清除。平台仍支持多选。

编辑仅改上传清单副本，原文件不变；上传清单按实际内容重算大小和SHA-256。未完成上传固定其转换内容，刷新后使用非敏感的声明记录恢复同一副本；失败重试不重新创建版本。平台、准备JSON、版本身份或文件不同会拒绝续传，需修正或中止原上传。后台不接收用户实际参数值或业务令牌。

## 客户端使用

打开已安装插件的详情，先选择当前对话项目。参数表单显示当前安装版本，不以市场候选新版本的字段替代它。填写必填参数，再核对当前项目权限并授权；之后检查业务账号和连接。无参数、无业务认证声明的阶段按原流程跳过。

参数存入现有keyring安全存储，普通配置文件只保存安全引用及随机代次。参数按当前账号会话、企业空间、项目和connector隔离；接口只回显非敏感值和密钥“已配置”标记。已保存密钥留空保持，显式勾选清除才移除；清除必填密钥导致校验失败时原配置保留。写安全存储或原子引用提交失败，不能显示保存成功。

保存参数会改变运行权限代次，停止此项目的旧运行时及依赖它的运行时，清除旧连接结果并回收已打开插件页面。启动进程前加载参数；配置损坏、密钥缺失、必填为空或账号范围改变时拒绝启动，不静默退回主机同名环境密钥。

连接账号由用户点击发起；等待期间只轮询声明的只读status。等待最多五分钟，可停止等待，旧结果和旧地址不得完成新请求；停止等待不撤销第三方已授予的权限。账号断开须显式确认，调用声明的logout并重新检查status确认为false，随后关闭同一插件账号范围中相关运行时及页面。插件数据目录可能由多个项目共用，确认时会显示此影响。

业务工具分发前重新检查账号；依赖插件也核对参数、项目权限、启用及业务账号。账号失效时返回明确准备错误，不自动登录或调用生成/付费工具。认证工具调用有30秒期限，同一connector防止并发账号操作；状态/操作完整响应不写入日志或市场，前端只收到布尔结果和经过校验的登录地址。

## 验证与恢复边界

类型、lint、双模式编译和本地浏览器边界记录见`capability-market-implementation.md`。浏览器使用正式组件与本地接口/时钟替身，不能据此宣称真实第三方登录、系统安全存储、进程回收、云发布或跨平台端到端通过。

旧v2缺安装依赖快照、旧账号会话下的指针范围及已下架版本恢复仍在后续实施中；当前提示修复不代表恢复闭环已完成。第三方系统钥匙串及供应商忽略目录环境的行为也须实机核对，不能以HOME隔离代替这项证据。

## 恢复旧安装记录

插件详情的“恢复安装记录”先检查本地包及其精确版本依赖，再展示账号/权限影响供确认。检查不下载或执行包；确认只恢复同版本的指针和记录，并关闭受影响运行时与页面。缺失或损坏的依赖需先经原安装入口修复。

当前账号仍有发布范围权限时，下架的完整本地版本可恢复元数据；删除、软删除或无权读取的版本不能恢复。此入口不授予重新下载或安装权限。账号会话/企业空间变化后，原范围参数、业务凭据和私有数据保留，当前范围需重新配置及授权。

提交期间先持久化停用，再切换指针与发布可用状态；失败尝试恢复原记录。中断或回退失败时保留不可用状态和包文件，重新打开入口检查，不自动沿用原账号权限。当前功能不提供任意版本降级。

## 本地版本与回退

已安装插件的详情提供“本地版本与回退”。版本来自成功提交的本地收据；列表按页读取，当前版本会单独标记。收据缺失或损坏的历史版本不能确认切换。

选择“检查此版本”只验证保留的包、精确依赖、平台和当前发布范围，不下载或执行插件，也不改变安装；检查期间可以关闭弹窗停止等待。下架版本仅在当前身份仍有权限时检查元数据，删除或越权版本拒绝，不授予重新下载权限。

确认前会列出需要一并切换的本地插件依赖、保留的技能版本、受管OfficeCLI，以及当前项目权限/参数声明的变化。缺少精确依赖或被其他能力固定引用时显示阻止，并提供相应市场跳转；不静默破坏其他能力的版本约束。

切换前结束工具调用并关闭相关插件页面。确认时再次核对账号、安装记录、授权、指针、收据、包和服务端计划；变化后必须重新检查。提交期间不能关闭确认弹窗。执行继续使用原安装事务，失败尝试恢复当前版本及派生技能；回退未完成时保留备份并明确报错。

保留当前范围的参数、私有数据、对话历史和选择，不重放历史授权，也不复制旧账号秘密。权限仅按当前仍允许的范围衔接，版本或依赖的权限/配置声明变化后需重新检查。成功后关闭弹窗会刷新正式详情的已安装版本，再按原准备面板核对项目授权、参数和业务账号。

当前验证覆盖正式组件的本地接口边界，不代表真实磁盘/DB故障、第三方账号、跨系统或进程崩溃已经验收。对保留.venv/node_modules的技能，按既有受管边界校验源码；经过旧格式兼容修复的SKILL.md可用原算法还原候选原文，只有重放修复与当前文件完全一致、且原文完整文件树与服务端摘要匹配才通过。其它无法证明的改动仍拒绝。


## 下架、权限与移除

下架停止新安装，但保留当前身份仍有发布范围权限的本地版本。后台清理只处理正式服务返回的删除/不可访问状态；清理前重新核对账号和安装快照，避免旧响应应用到新安装。

手动移除目前会先检查共享引用，发现其它能力仍依赖时阻止并显示原因；损坏但路径和租约可安全核对的安装也能移除。完整的依赖影响确认与共用组件保留仍在后续实施中。需要断开业务账号时先走原连接器/插件准备中的显式断开；本机卸载不能视为供应商服务端授权已全部撤销。

当前卸载不声称已经清理全部账号范围私有数据与安全存储记录；其显式选择、失败续清和持久恢复仍待补齐。对话历史和工作区文件不随组件删除。
