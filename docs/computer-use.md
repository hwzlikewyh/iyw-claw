# 电脑操作与压缩摘要

应用启动时由受管环境自动准备电脑操作组件；在「设置 → 技能包 → 电脑操作」
打开电脑操作开关。设置页不显示驱动信息或单独安装、卸载入口。
电脑操作开启后，可在对话输入框的「＋ → 共享窗口…」选择窗口，在窗口卡片里
选择「可读取」或「可操作」。共享之后，菜单可管理共享窗口或停止共享。
电脑操作关闭或当前宿主不支持时，「＋」菜单隐藏此入口并关闭窗口面板；重新开启后
需主动再次打开面板。选择窗口不会自动开启功能。
设置页也提供同一个共享窗口面板。状态栏的电脑图标提供窗口、应用和可选的整屏共享。共享范围适用于当前宿主
上获准使用内置工具的所有 Agent；每项可选择仅读取或读取并控制。
共享默认关闭，授权不在重启后恢复。闲置到期、停止共享或关闭开关会撤销授权。
操作记录显示发起操作的 Agent；停止浮层和全局快捷键可立即停止并撤销共享。

桌面驱动由 Fusion 受管环境统一安装与修复，固定为 cua-driver 0.32.0。
「设置 → 运行环境」可以重新检测、查看组件状态和修复运行环境；修复使用既有
初始化事务，复用校验通过的组件。进度与结果按当前连接的宿主隔离，切换页面
不会中断修复。失败时保留错误和重试入口；内置星河资源损坏仍需重新运行应用安装包。
旧 open-computer-use 的项目内技能、安装实现和 PATH 注入已移除；
升级仅清理应用所有的 MCP 注册、技能链接和受管目录，保留用户自建安装。

远端工作区控制连接的远端宿主。独立服务端需要在有桌面的环境显式设置
`IYW_CLAW_COMPUTER_USE=1`；无头 Docker 不提供此功能。
支持 Windows 10+、macOS 14.4+ 和 Linux X11，应用自身仍支持原有最低系统版本。
macOS 正式包还需签名：辅助程序独立持有系统权限，调用方和驱动映像都经过校验。
现有 ad-hoc macOS 发布流程保留应用其他功能，但电脑操作入口不可用。

压缩分隔线有真实摘要时显示「查看摘要」，默认折叠。
实时 ACP 压缩更新和摘要分片、远山历史、星河历史都使用同一展示入口。
旧记录没有摘要、或远程压缩只保存加密状态时，不显示摘要按钮。

## 发布准备

1. 部署 Fusion 的分发源码，通过既有脚本上传官方固定摘要的 cua-driver 制品；
   为包含本功能的应用版本生成新版环境绑定。已有老版本绑定保持可修复。
2. 使用正常桌面构建入口准备同版本 helper 与环境引导程序；不要跳过伴生程序
   校验，也不要分发 cargo check 生成的空占位文件。
3. macOS 正式构建设置 `APPLE_SIGNING_IDENTITY` 和对应 `APPLE_TEAM_ID`，
   主程序与 helper 使用同一团队签名，执行现有签名、公证与安装包验证。
4. 服务端发布包同时包含 `iyw-claw-server`、`iyw-computer-helper` 和 `web/`；
   自更新与安装脚本会核对、替换并回滚对应文件。

本轮已按用户授权完成官方归档预下载、TOS 上传和完整回读校验；正式驱动版本
`0.32.0` 已发布并配置 stable 策略，六个平台工具制品都是 ready。
由于 `0.1.257` 至 `0.1.259` 已发布，新的五平台环境绑定改用 `0.1.260`，
线上 resolve/download 和完整下载 SHA-256 校验全部通过。
驱动目录隐藏，支持的平台初始化环境时自动安装，授权默认关闭。需正常构建和发布
`0.1.260` 或更新版本才能交付新功能。线上新上传白名单仍需随 Fusion 部署；
本轮通过本机新版发布逻辑与 DBX 完成分发数据，没有部署、Git 提交或推送。
配套记录见 Fusion 的 `docs/native-computer-driver-preparation.md`。

当前验收记录见 `docs/computer-use-integration-plan.md`；源码接入与本机检查
不等于发布包和真实桌面操作已验收。
