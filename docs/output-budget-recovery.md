# 输出额度中断恢复

2026-10-12 用户授权让输出预算失败先自动续接，仍无法完成时再提示。

主窗口的直接用户会话在 `max_tokens` 或带 `max_output_tokens` 的模型错误后，
沿现有恢复入口累计最多 3 次自动续接。次数属于当前用户轮次；新用户消息重置，
最终成功或失败事件保留实际次数。普通计划/承诺续接继续只自动执行一次。

待处理权限、用户问题、渠道确认、工具、委托或后台任务会阻止自动续接。
用户取消沿现有命令通道处理；原子事件门禁重新检查代次和可续接次数，
防止旧轮次覆盖新轮次。次数耗尽或遇到其他不可恢复错误后，复用现有失败提示。
续接提示要求检查工具结果和工作区状态，从未完成处继续，避免重放成功操作。

配套 Fusion 为缺省的 DeepSeek 原生 Responses 请求发送有上限的 128K 生成额度，
并在兼容模型目录提供 `none` 思考档位；当前思考设置由用户选择，不自动改变。
星河生成的内核模型目录接受 `none`，用户可选档位继续由后台目录控制；
前端已有“不思考”名称与说明，复用现有选择、确认和保存流程。
完整设计见 Fusion 仓库的 `docs/deepseek-output-budget-recovery.md`。
