# 浏览器设置

桌面端入口：设置 → 常规 → 浏览器。默认使用轻量 WebView。用户和 Agent 共享原页面，
程序负责内核选择；详细能力和数据边界见 [双内核浏览器](browser-engines.md)。

## 设置项

| 设置 | 行为 |
| --- | --- |
| 显示内置浏览器 | 默认开启；关闭后隐藏入口并禁用内置浏览器工具 |
| 启用完整浏览器 | 默认关闭；开启且完整组件可用时使用 Chromix |
| 当前使用 | 显示实际内核；活动任务阻止切换时显示待生效 |
| 完整内核 | 显示安装状态，提供安装、检查修复和进度 |
| 登录与网站数据 | 说明持久登录与各内核缓存分别维护 |

完整内核安装使用现有 Fusion 受管事务。未安装、下载失败或校验失败时轻量浏览器
仍可使用。安装过程中可以改变启用开关；安装完成只刷新组件状态，遵循最新偏好。
新安装默认跳过 Chromix 和 agent-browser，已有安装保留。

内核切换在所有标签关闭、Agent 回合租约释放且活动下载结束后生效。隐藏面板会
隐藏页面，仍保留页面状态和任务持有；不能将隐藏视为内存已释放。

## 网站数据

每个内核使用持久 Profile。用户与 Agent 在同一内核共享 Cookie、LocalStorage、
IndexedDB 及缓存。同次运行中的内核切换通过 Cookie API 迁移普通 Cookie，不能
直接共用数据目录。缓存、Service Worker、IndexedDB 和表单状态不跨内核复制；
设备绑定或分区 Cookie 可能要求重新登录。重启应用后各内核保留自己的数据。

WebView 使用系统浏览器引擎，兼容性受系统版本和网站策略影响。修改 User-Agent
不能保证通过站点限制；网站验证失败时提供人工接管，用户也可以启用完整内核。

## 历史外部浏览器

当前桌面版不依赖 OpenCLI 或外部浏览器扩展。旧的扩展准备、Chrome/Edge 连接和
外部登录态交接不再参与默认调用链；已有用户扩展文件保留。
服务器或远程环境的联网工具通过原有联网工具页管理，不打开服务端路径。

## Agent Reach 状态

已有 iyw.internet.agent_reach.status.v1 能力复用受管 agent-reach doctor --json，
经会话鉴权返回渠道和后端状态。实际搜索、读取继续使用对应平台工具；诊断不会
安装组件、导入凭据或启动 Python MCP 常驻进程。

## 验证

交付检查包括 TypeScript、定向 ESLint、JavaScript 与 JSON 语法、Rust 格式解析及
静态调用链审查。遵循 AGENT.md，不在本机编译或启动桌面应用，不运行测试。
真实登录、站点限制、下载和跨平台行为需要指定环境中的实机验收。
