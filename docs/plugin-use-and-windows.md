# 插件使用与独立窗口

右侧首页只显示本机已安装的插件，包括没有独立页面的技能、工具插件。
“查看所有插件”进入市场；安装成功后通知当前窗口及同源窗口刷新。
市场数据只补充显示名称与图标，不决定本地安装版本或可用性。

有应用页的插件点击后直接在右侧边栏打开，对话及输入框继续显示；尚未发送消息的草稿使用临时插件上下文，
打开、配置、加载和编辑均不创建对话记录，也不将插件名写成会话标题。
用户从输入框或插件界面首次发送消息时，原有流程才创建会话并关联临时上下文，
保留正在编辑的页面、租约和数据。纯技能或工具插件选入当前消息。
安装默认授权、配置和业务账号仍通过已有插件准备流程校验。

## 列表与快捷入口

首页将页面与技能插件合并为连续列表，按名称排序；窄栏单列，足够宽时双列。
有本地应用入口的项目均显示“打开”，其余项目显示“加入对话”。
MCP 应用页与 OpenFilm Studio 均可在没有会话记录时打开。读取应用目录期间
不会把尚未返回的页面误判为技能插件；目录失败保留错误提示与刷新入口。

应用页复用右侧可调整宽度的工具栏区域，工具栏可关闭、放大或移到独立窗口。
只有用户点击放大时才进入全屏。收起边栏后，已打开的应用可从收起栏单个图标恢复，不重新启动插件。
关闭插件或移到独立窗口后，相应快捷入口随页签移除。

图标使用插件市场已有的 `iconUrl`：发布者可在发布表单或“编辑资料”的图标 URL
中配置，每个插件独立设置。列表、页签、收起后的快捷入口共用该图片；未配置、
离线读取不到资料或图片加载失败时显示名称缩写。保存资料会通知同源窗口刷新。

插件软件拥有界面不等于发布包已接入宿主页面。LibTV 0.2.3、Excel 0.2.4
未注册 `app`，选入对话后由助手使用其能力。OpenFilm 的已发布版本通过明确的
桌面兼容入口独立打开 Studio，详见 `plugin-list-and-openfilm.md`。

## 窗口操作

- 会话移到新窗口：通过现有交接快照传递侧栏开关、宽度、当前栏目、应用引用和
  输入框插件选择。插件先响应保存协议，目标再按安装目录恢复页面。
- 插件单独移窗：点击页面工具栏的“移到新窗口”按钮，也可拖离导航条或使用右键菜单。
  已发送会话和未发送草稿中的 MCP 应用均可移窗，来源调用插件保存协议，
  新窗口完成应用握手后才显示并移除来源标签；启动失败保留来源页面。
- OpenFilm Studio 同样支持独立窗口，包括无会话打开；新窗口复用对应 Studio 工作区，
  通过宿主重新获取打开地址，地址不写入窗口路由。移窗本身不创建对话记录。
- 独立插件窗口继续使用原宿主桥接、租约、权限检查、下载和关闭前保存流程。
  与原对话的模型信息和消息发送通过独立随机通道关联，原窗口仍校验当前对话
  和连接身份。原对话关闭或切换后不会误发到其他对话。
  草稿独立窗口保留临时工作区，关闭来源草稿后仍可使用插件页面；向助手发送消息
  仍须来源草稿存在且处于当前窗口，防止误发到其他对话。关闭独立窗口后回收保留的上下文。

插件重新载入时恢复的是其保存的数据，不复制 iframe 内存。插件必须正确实现
保存协议；没有完成保存时关闭操作会保留当前页面。

## 草稿打开与启动恢复

2026-11-17 恢复所有已声明应用页的插件直接打开：草稿上下文只保存在运行进程中，
不新增或修改数据库表。插件实例继续走既有授权、工具调用、同步和关闭流程。
验收重点为打开/关闭不产生会话、插件内首次发送、首次发送后保留页面、切换草稿及账号隔离。

点击后立即在右侧边栏显示准备状态，收到应用实例后由页面内加载状态接续。重复点击只启动一次；
切换或关闭草稿后，过期请求返回的实例会释放。草稿首次发送不重置插件启动或页面。
iframe 首次加载早于宿主注册事件时补发握手，收到首条有效协议消息后停止；
超时提示保留原 iframe，迟到的成功初始化仍可恢复。启动失败或租约失效时可“重新打开”，
重开前遵循已有保存协议，并重新读取目录、校验授权、创建实例。

本次验证使用全项目 TypeScript、相关源码 ESLint、Rust 语法解析及差异检查。
按仓库规则未新增或运行测试、未在本机编译或启动桌面端。真实插件启动、保存、
首次发送和跨窗口交互仍需客户端实机验收；静态检查不替代这些交互验证。
