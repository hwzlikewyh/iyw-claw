# 插件使用与独立窗口

右侧首页只显示本机已安装的插件，包括没有独立页面的技能、工具插件。
“查看所有插件”进入市场；安装成功后通知当前窗口及同源窗口刷新。
市场数据只补充显示名称，不决定本地安装版本或可用性。

点击插件自动关联当前对话，并通过已有插件准备和技能投影入口启用所需能力。
带应用的插件打开右侧页面，其余插件选入当前消息。安装默认授权沿用运行时
已有策略；普通插件详情不显示额外授权步骤，实际缺少参数或外部账号时仍需处理。

## 窗口操作

- 会话移到新窗口：通过现有交接快照传递侧栏开关、宽度、当前栏目、应用引用和
  输入框插件选择。插件先响应保存协议，目标再按安装目录恢复页面。
- 插件单独移窗：拖离导航条或右键选择“移到新窗口”。来源调用插件保存协议，
  新窗口完成应用握手后才显示并移除来源标签；启动失败保留来源页面。
- 独立插件窗口继续使用原宿主桥接、租约、权限检查、下载和关闭前保存流程。
  与原对话的模型信息和消息发送通过独立随机通道关联，原窗口仍校验当前对话
  和连接身份。原对话关闭或切换后不会误发到其他对话。

插件重新载入时恢复的是其保存的数据，不复制 iframe 内存。插件必须正确实现
保存协议；没有完成保存时关闭操作会保留当前页面。

## 合并验证

基于远程 `main` 的最新代码整合，保留既有窗口恢复与画布消息绑定修复。

- 全项目 TypeScript：`tsc --noEmit --incremental false` 通过。
- 相关源码 ESLint、差异空白检查通过。
- `cargo check --offline --features tauri-runtime` 通过；存在仓库既有警告。
- 按仓库 AGENTS.md 未新增或运行测试套件。桌面拖拽、插件真实保存与消息发送
  尚未完成实机验收；编译检查不替代这些交互验证。
