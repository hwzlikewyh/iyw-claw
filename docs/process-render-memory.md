## 已修复的问题

- 连续调用工具时，上一条完成会暂时让过程区被视为完成，下一条开始后又自动展开。现在最后一段过程等待整轮回复结束；手动展开和收起不再被任务状态覆盖。

- 展开的过程区以前会挂载全部工具卡片。现在复用已有 virtua，在滚动视口与前后各 200px 范围内挂载卡片；普通工具卡片和工具结果的展开状态保存在过程区中，离屏卸载后可恢复。
- 工具适配会创建新对象，现在字段未变化的工具卡片跳过重复解析和渲染。
- 隐藏会话保留草稿编辑器时，停止挂载消息列表，后台任务仍由原运行时管理。
- 超过 50,000 字符或 1,000 行的代码和日志不再生成 Shiki token 和逐词节点，以轻量文本显示。全文、复制和原有行号保留，小段代码继续高亮。
