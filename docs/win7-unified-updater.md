# Win7 统一安装向导更新

2026-11-17：安装、更新入口统一由 `iyw-claw-installer` 提供。

新客户端收到同 release、同平台身份的签名 bootstrapper 时，预下载应用和向导，
再交由向导自动补齐 Windows 前置组件。向导准备完成并验证父应用身份后才发就绪，
应用检查空闲状态后正常退出；准备失败或需重启时保持当前应用，返回具体原因。
Win7 x64/x86 使用对应 NSIS 的内部静默兼容路径；普通 Windows x64 保持直接载荷部署。

新向导最低发布引用为 0.2.8。协议 2 原字段保持，新增 `nsis_targets` 能力；
失败回执仅写 `error_pid`，避免旧客户端当成成功 `pid`。没有同发布向导的历史版本
仍沿用旧更新通道。macOS/Linux 的本次应用更新路径保持原有行为。

发布流程为三种 Windows 目标分别提供带 minisign 的向导记录，文件均来自同一个
签名 Win32 引导包，不内嵌应用。Fusion 按平台身份登记并保留旧 NSIS 顶层字段；
旧的 0.1.350 等完整发布没有 Win7 向导附件时仍允许同步，不要求修改已发布制品。

验证：修改的 Rust 文件通过 stable rustfmt 格式/语法检查，发布 Node 脚本通过
语法检查，两份工作流 YAML 解析通过。遵守仓库约束，未运行本地桌面构建或测试；
后续应用需经 GitHub Actions 编译，并在 Win7 真机验收安装、自动更新与系统重启。
