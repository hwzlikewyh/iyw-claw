# 主程序内嵌 Obscura

桌面主项目通过 Rust 库直接链接 Obscura，后台浏览任务优先使用它，适用的失败再回退
现有内置浏览器。无需独立 Obscura 可执行文件、外部 MCP 服务或新增 Fusion 环境组件。

## 接入范围

- 固定上游 v0.2.7 对应提交 `0ecc41770da5c5300227dd83a15bfa1e5100d5d4`，启用原生渲染。
- `tauri-runtime` 启用内嵌依赖；Win7 和 32 位目标不链接引擎，继续使用原浏览器。
- 服务端维持当前不支持本机浏览器的行为，本轮不扩展服务端浏览器接口。
- 原有 `browser` 及兼容工具进入同一 BrowserSessionManager；不增加 Agent 配置项。
- 后台引擎惰性初始化，每个 Agent 连接、会话和回合独立管理任务；V8 创建、调用和销毁
  固定在同一个工作线程。CDP 请求在进程内分派，不监听端口，不经过 WebSocket。
- 后台页面使用任务内临时状态，不导入用户现有 Cookie，不读写另一引擎的 Profile。

## 选择与回退

已有内置标签保持原路径。没有已有内置标签的新任务优先 Obscura，支持打开、快照、
读取、点击、填写、按键、滚动、有界等待和普通截图。全页/引用标注截图、过滤读取、
局部快照和高级命令交给现有浏览器。现有轻量内核仍可能不支持部分高级选项，此时
返回原有错误，不自动安装或启用完整内核。

首次引擎不可用、导航失败、读取超时或截图失败，且任务尚未进行交互时，可回退一次。
一次工具调用共享超时预算；未交互的 Obscura 操作只使用剩余预算的一半，为回退留出
时间。回退后同一任务固定走内置路径，旧 Obscura 标签全部释放。

取消、关闭浏览器、参数错误、过期引用或定位失败不触发自动回退。交互开始后，即使
调用失败，也保守地保留结果不明标记；不自动换引擎重复点击、填写或提交。交互后
不支持的操作返回明确错误，保留当前任务页面供继续检查。

`present` 和 `request_user_action` 明确转到现有内置浏览器，重新打开当前 URL。
这不是迁移原页面：Cookie、登录、表单、脚本堆和其他页内状态不转移，可能需要重新
登录。返回 `fallback.stateReset=true`、新的 `targetTabId` 和失效标签列表，后续必须
使用新标签和新快照。高级命令的回退返回错误及 `recovery` 快照，不执行原命令。

## 回收与日志

关闭最后一个后台标签会停止工作线程。结束回合、结束连接、关闭浏览器或应用退出
都会取消并释放对应任务。后台标签使用全局配额，沿用现有标签数上限，避免每个回合
各自获得一整套配额。截图写入现有用户目录并受截图配额管理。

宿主只记录阶段、协议方法和错误码，不把页面内容、脚本、Cookie 或截图写入新增日志。
上游引擎仍使用其自身日志行为。

## 构建与验证边界

新增依赖带入 V8 和渲染代码，首次构建、安装包大小和内存基线需要在发布环境评估。
源码固定版本与锁文件一起维护；本轮为满足上游要求，仅同步升级锁定的
`compression-codecs` 和 `compression-core`，其余已有依赖版本保持不变。

按 AGENTS.md/AGENT.md，本机不编译、打包、启动桌面端，不新增或运行测试。当前只完成
依赖解析、Rust 格式与语法解析、工具描述一致性以及静态调用链检查，不能代替编译或
真实网站验收。

实施进度：嵌入依赖与固定版本已接入；路由、取消、回收和安全回退已接入；依赖解析、
语法和静态一致性检查已完成。发布环境仍须验证各目标平台编译、公开网页与 SPA、点击与输入、截图、
故障回退、人工登录和并发隔离；完成前不宣称已通过运行验收。
