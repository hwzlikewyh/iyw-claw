# 回复统计准确性修复

## 目标与边界

按截图调整回复下方的首次响应、开始思考、正文首字、正文字符和工具调用统计，并修复展开过程后通用工具分组仍然折叠的问题。沿用现有事件与组件，不修改后端协议、持久化或计费规则。

验收标准：

1. 首次响应、思考和正文首字采用同一后端时钟的事件时间差，不把前端批处理、重连补发或历史恢复时间作为首事件时间。
2. 工具调用按原生 ID 去重，实时与完成展示使用一致口径；无法确认完整调用数时隐藏该项。
3. 正文字符对应当前展示的正文，按 Unicode 码点计数；没有正文时隐藏。
4. 缺失、非法或零次调用不展示占位文案；没有可展示统计时不保留空行。回复生成中点数随流式输入、正文和思考变化；后端用量/账单到达后优先使用权威数据。
5. 点击展开过程即可看到通用工具分组中的各个步骤，不再额外点击分组摘要。保留固定高度、内部滚动、隐藏滚动条和按需查看单步参数/输出。

## 步骤 → 验证方式

1. 修正首事件记录（完成） → 静态检查事件入队前取样、事件序号去重、历史恢复与时间基准对齐。
2. 调整调用、字符和空统计展示（完成） → 核对分组、合并和实时到完成转换，确认无占位或重复计数。缺少原生调用 ID、图片块不能映射为调用次数时隐藏总数，不把图片数量当作调用数量。
3. 过程展开（完成） → 只在过程容器中展开通用工具分组，步骤沿用现有工具组件；不改变正文或其它入口的分组方式，保留专用目标、后台和子代理卡片。
4. 静态检查与交付（完成） → 最终 TypeScript 无输出类型检查、定向 ESLint、Prettier 和 diff 检查通过；新改统计函数的复杂度不超过 10，函数不超过 50 行。原连接上下文文件有既存格式问题，已与 HEAD 比较，本次不新增此类问题；未格式化无关代码。按仓库约定未新增或运行应用测试，未在本机编译或启动桌面。
5. 流式点数更新（完成） → 从模型目录价格计算本轮实时变化，扣除后端已上报 Token 避免重复计入；已确认点数到达后采用后端金额。前端文本分词仅用于即时近似，后端账单仍是最终值；费率分类无法可靠拆分时不虚构金额。TypeScript 无输出检查、定向 ESLint 与 diff 检查通过。

首次响应表示从本轮后端开始时间到首个响应事件的间隔；开始思考、正文首字分别表示到首个对应事件的间隔，不代表累计思考耗时。只有思考状态而没有文字时可采用该事件后端采样时间，不捏造思考内容。缺失后端首事件时间的旧历史不会显示“未记录”。

尚未打包、发布或进行客户端实际点击验证；完成后需覆盖截图中的长过程、少量步骤、思考与工具交错、运行中重连和历史重新打开。
